# 상세 AI 사용법 보강 · 2026-11-04

요약 안내만으로는 처음 사용하는 수강생이 질문·자료 첨부·수정·검토를 실행하기 어려워 웹에 상세 사용법을 추가했다. 기존 실제 문서 실습 6개, 반별 3시간 편성, 원문과 교재 PDF 2.1판은 유지한다.

## 학습 내용

1. AI·LLM·모델·서비스·기능을 구분하고 AI와 사람의 역할 정하기
2. 새 대화 → 요청과 자료 입력 → 답변 대조 → 후속 수정 → 결과 저장
3. 목적·자료·독자·형식·조건을 사용한 요청 작성과 5개 항목 구성기
4. 사실을 유지하면서 구조·말투·분량을 수정하고 전후 비교
5. PDF·HWP·TXT·이미지 준비, 읽힌 범위 확인, 본문·붙임 대조
6. 일반 대화·제공 자료 분석·최신 웹 검색 구분
7. 무료·유료의 기능·사용량·검토 시간·데이터 관리·비용 비교
8. 핵심 주장·숫자·날짜·단위·조건·누락을 원문과 검증
9. 자료 전송·권한·개인정보·간접 식별자·자료 속 지시 구분
10. 컨텍스트 층, 활성 자료·제외 자료·작업 상태 관리
11. RAG의 등록·검색·생성 단계와 질문별 소스 선택·인용 검토
12. 하네스 구성 요소와 사람이 운영하는 추출·작성·검토·저장 절차
13. 확인한 사실·미결·고정 조건·다음 행동을 새 대화에 인수인계
14. 고정 규칙과 변수 분리, 공고·업무계획 A/B 템플릿 시험
15. 생활·학습·취업·사무 사례별 자료·첫 요청·후속 요청·검토

각 주제는 개념 설명, 직접 하는 순서, 요청문 또는 전후 비교, 강사가 작성한 점검 예시, 직접 연습·검토 항목·펼침 해설, 문제 해결, 출처로 구성했다. 실제 캡처가 있는 주제는 기존 검증된 화면을 해당 절차 옆에 재사용한다. 가상 메모와 강사 예시는 실제 AI 응답 캡처와 구분한다. 새 AI 실행을 했다고 주장하지 않는다.

초급 목차 11개, 중급 목차 13개에는 공통 주제가 중복 포함된다. 주제 수가 수업 시간 수를 뜻하지 않으며 기존 개념·시연 30분, 실습 120분, 휴식 20분, 정리 10분은 유지한다. 3시간 안에 모든 상세 문장을 강독하는 편성으로 바꾸지 않았다.

## 출처와 내용 경계

공식 자료는 2026-11-04에 확인했다. 아래 개념을 참고해 워크숍의 공개 문서와 가상 메모에 맞는 예시·연습·오류 상황을 직접 구성했다. 서비스별 고정 가격·토큰 용량·업로드 횟수·기능 순위를 보장하지 않는다.

- [Google LLM 입문](https://developers.google.com/machine-learning/crash-course/llm): 언어 모델·문맥·토큰의 기초
- [OpenAI 요청 작성](https://learn.chatgpt.com/docs/prompting): 결과·자료·독자·조건·후속 수정
- [OpenAI 파일 작업](https://learn.chatgpt.com/docs/artifacts-viewer): 파일 제공과 결과 검토
- [OpenAI 웹 검색](https://learn.chatgpt.com/docs/web-search): 현재 정보 요청과 출처 확인
- [OpenAI 요금제 안내](https://learn.chatgpt.com/docs/pricing): 사용량·구독·API 과금의 구분
- [OpenAI 개인화](https://learn.chatgpt.com/docs/personalize): 개인화와 대화·원문의 구분
- [Google 소스 관리](https://support.google.com/notebooklm/answer/16215270?hl=ko): 지원 자료·선택 소스·URL 가져오기 범위
- [Anthropic 컨텍스트](https://www.anthropic.com/research/effective-context-engineering-for-ai-agents): 지시·자료·대화·상태의 구성과 정리
- [Anthropic 하네스](https://www.anthropic.com/research/managed-agents): 모델 호출·도구·상태를 연결하는 실행 환경

프롬프트를 복사해 실행하는 학습과 코딩된 에이전트 하네스 구현은 구분해 설명한다. RAG 사용·인용 존재·유료 구독이 사실 검토를 대신한다고 가르치지 않는다. 스캔·복잡한 표·개인정보·원문 상충 처리는 수업 자료를 확인하는 실무 안내이며 기관별 승인이나 개별 법률 판단을 대신하지 않는다.

## 유지보수

주제 데이터와 관련 링크: `src/usage-guide-data.js`. 화면·주제 전환·다운로드: `src/UsageGuide.jsx`. 원문·교재용 개념 데이터: 기존 경로 유지. `content/web-copy-revision.json`에서 개념 뷰 파일 변경을 기록하고 PDF 해시와 기존 교재 개념 데이터 해시는 고정한다.

주제별 TXT에는 본문·표·절차·요청·점검 예시·연습·문제 해결·출처를 담는다. 캡처 이미지는 TXT에 포함하지 않으며 웹의 확대 보기를 사용한다. 요청문 구성기에 입력한 임시 값은 복사해서 보관해야 하며 별도 자동 저장 대상으로 추가하지 않았다.
