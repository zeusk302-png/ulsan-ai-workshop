# 초급반 3교시 웹 개정

사용자가 승인한 개념 그림·측정 그래프를 웹에 적용했다. PDF v2.1은 수정하지 않는다. 기존 7단계 흐름과 15개 주제 참고서는 유지하고, 주 수업은 `#basics?unit=ai`에서 진행한다.

| 대단원 | 중단원 | 소단원 | 시간 |
|---|---|---|---|
| 1교시 AI 이해·선택 | AI 원리, 대표 모델, 무료·유료, 환각·책임 | 각 중단원 3개 | 50분 |
| 2교시 요청·대화 운영 | 토큰, 컨텍스트, 요청 설계·수정 | 각 중단원 3개 | 50분 |
| 3교시 자료 기반 작업 | RAG 원리, Gemini Notebook, 공개 문서 실습 | 각 중단원 3개 | 50분 |

휴식 두 번 각10분과 마무리10분을 합쳐180분이다. 상세 단원 시간은15/10/10/15, 10/10/30, 10/10/30분이다. 교시 내 실습 기록은 기존 ID `meeting`(15분), `adapt`(35분), `email`(35분)을 사용하며 별도 추가 시간이 아니다. 중급반의 180분 편성은 유지한다.

## 내용·출처

- 모델·서비스·도구, 학습/생성, 무료/유료, 토큰·컨텍스트·메모리, 요청 수정, RAG 준비/검색/생성, 소스·인용 대조를 구분한다.
- 모델·기능은2026-11-05 OpenAI·Google·Anthropic 공식 안내를 확인한다. 제조사 제품 위치와 독립 비교를 구분하고 구독료·정확도·토큰 한도를 추정치로 고정하지 않는다. 기능·모델 접근은 계정과 배포 상태에 따라 확인한다.
- Mata 사건의5,000달러는 공동·연대 금전 제재로, Al-Haroun 사건의 조치는 규제기관 회부로 설명한다. 형사 벌금·유죄·징계 확정과 혼동하지 않는다. 원문 판결 링크를 제공한다.
- 이미지2개는 승인한 AI 제작 개념도다. 토큰 그래프는 보존 공고와 강사 작성 대화/요약의 본문을 `cl100k_base`로 측정한 예이며4,090/6,317/4,253토큰이다. 실제 서비스의 한도·응답 품질을 측정한 것은 아니다.
- 기존31개 캡처의 출처·바이트는 보존한다. 새 단원의 실제 화면은2026-10-14의 기존 실행 기록으로 구분한다.

## 접속·저장

홈페이지는 수업 작업 메뉴와 분리된 로비다. 로비 히어로에 강의 제목·소개·홈페이지 QR을 함께 배치하고, 아래에 기초반·심화반의 대상·핵심 내용·3시간 안내·입장/상세 구성 링크를 제공한다. 과정에 입장하면 기존 목차와 작업 메뉴가 나타난다. 수업 화면의 상단에도 접속 QR 확대 버튼을 제공한다. QR은 외부 생성 서비스 없이 생성했으며 원본 이미지의 해독값은 `https://zeusk302-png.github.io/ulsan-ai-workshop/`이다. 조용한 여백과 흑백 대비를 유지한다.

저장 키와 기존 작성 글·이전 검토 기록은 유지한다. 바뀐 초급 과제의 검토 기준은 선택 필드 `beginner`(revision `beginner-2026-11-05`)에 저장하며 이전 완료를 자동 승계하지 않는다. 중급은 기존 `workflow` 필드를 사용한다. JSON 백업은 원래 기록과 새 기록을 함께 포함한다.

## 확인 범위

단위 테스트25개, Vite 빌드,10개 단원의 React 정적 렌더링 구조, 이미지·측정 데이터 해시와 QR 원본 해독을 확인했다. `scripts/verify-beginner-structure.mjs`는 브라우저가 아닌 서버 렌더링 검사다.

현재 Work 설정에서 로컬 브라우저 제어가 비활성화되어 있어 실제 클릭·반응형 배치·스크린샷 QA는 이번 변경에서 실행하지 못했다. 정적 검사와 화면 검증을 같은 결과로 표시하지 않는다. 외부 AI 새 응답·수강생 계정 한도·실제 수업 효과도 검증 범위에 포함하지 않는다.
