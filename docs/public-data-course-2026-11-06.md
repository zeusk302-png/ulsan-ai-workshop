# 실제 울산 상가 공공데이터로 진행하는 중급 수업

기록일: 2026-11-06. 기본 교재는 자료 등록 → 기준과 실행 요청 추출 → 파일 작업 AI 실행 → 실제 파일 확인의 네 단계다. 처음 보는 사람이 셀 주소, 수식, 코딩을 먼저 배우거나 답안을 작성할 필요는 없다. 이 문서는 구현과 로컬 검증의 범위를 기록하며 새 개편의 공개 배포 완료를 뜻하지 않는다.

## 실제 입력과 보존 범위

소상공인시장진흥공단의 [상가(상권)정보](https://www.data.go.kr/data/15083033/fileData.do) 전국 배포 ZIP에서 울산 CSV 원본을 추출했다.

| 기준일 | 울산 원본 | 자료 행 | 항목 |
|---|---|---:|---:|
| 2026-06-30 | ulsan-202606.csv | 54,737 | 39 |
| 2026-09-30 | ulsan-202609.csv | 53,777 | 39 |
| 두 파일 전체 | 각 시점은 별도 유지 | 108,514 | 같은39항목 |

행을 복제하거나 오류를 주입하지 않았고 표본으로 줄이지 않았다. 원본의 공란·명칭·주소·좌표를 그대로 보존했다. 배포 출처, 전국 ZIP 이름, 원본 멤버 이름, 시점, 바이트 수와 SHA-256은 `content/public-data-course.json`과 `public/automation/public-data/provenance.json`에 남는다. 학생용 `data/ulsan-two-quarters.zip`의 두 CSV도 원본 바이트와 일치한다.

39개 항목에는 점포 식별자·상호, 업종코드와 이름, 시군구·행정동·법정동, 주소·건물, 경도·위도가 있다. 단순히 행 수만 큰 자료가 아니라 업종표 연결, 지역별 집계, 시점별 관측 비교와 위치 정보의 품질을 함께 다룰 수 있는 구조다.

## RAG에 등록할 실제 참고자료6개

기본 등록 파일은 `automation/public-data/references/all-references.txt` 한 개다. 여러 문서를 담은 통합 파일이므로 소스 목록이 한 개여도 정상이다. 참고문서는 다음 역할로 나누고 실제 공식 원문과 강사의 해설을 명시적으로 구별한다.

1. **P01 공식 파일 설명·기준일·원본 README**: 두 배포 파일의 출처와 시점, 사용 범위를 설명한다.
2. **P02 공식 OpenAPI 활용가이드 전체 문단 추출**: 공식 HWP의 본문100,418자를 보존했다. 원본 ZIP도 함께 제공한다. 문단 추출은 표의 셀 구조·쪽 배치·그림을 보존하지 않으므로 모호한 항목 대응은 원본으로 확인한다. 새로운 실무 사례를 덧붙여 공식 가이드 분량을 늘리지 않았다.
3. **P03 공식39항목 설명과 CSV 대응**: 공식 API의 실제 점포 필드와 원본 CSV 항목을 연결한다. 대응 주석은 강사 작성임을 구분한다.
4. **P04 공식2023 업종코드표**: 대분류10개·중분류75개·소분류247개의 공식 코드와 이름을 사용한다. 코드표 원본은CP949 CSV이며 제공 기준명은20230228이다.
5. **P05 자료 충돌·누락·명칭 차이·시점 비교 해설**: 공식 규정이 아니라 강사가 작성한 적용상 주의사항이다.
6. **P06 울산 분포 보고 업무 안내**: 분석 대상과5장 보고 구성, 입력·출력과 파일 확인 조건을 정한 강사 지시다.

공식 가이드와 항목 설명은 [공식 API 안내](https://www.data.go.kr/data/15012005/openapi.do), 업종표는 [공식 업종코드 자료](https://www.data.go.kr/data/15067631/fileData.do)에 근거한다. 확인한 공식 메타데이터의 이용조건은 ‘이용허락범위 제한 없음’이며, 제공기관·원문 주소·변환 여부를 함께 남긴다. 공식 HWP의 표지 날짜는2026년7월이고 파일명은260805다. 가이드의 갱신주기 설명과 포털 메타데이터가 다를 수 있으므로 이번 분석은 실제 다운로드한 두 기준일의 스냅샷을 명시한다.

## 수업의 네 단계

첫째, Gemini Notebook 등 자료 기반 AI에서 새 노트북을 만들고 소스 추가 → 파일 업로드로 통합 참고TXT를 등록한다. 점포 CSV 전체를 근거 검색에 넣어 합계를 추측하게 하지 않는다.

둘째, 등록한 자료에서 현재 적용할 뜻과 주의사항을 확인하고 **① 업무 기준과 주의사항, ② 다른 AI에게 그대로 줄 실행 프롬프트**를 함께 작성하게 한다. 답변이 가리키는 문서·원문 위치를 통합 참고자료에서 확인한다. 웹에 제시된 요청문은 질문의 시작점이고, 다음 단계로 옮길 것은 자료 기반 AI가 실제 작성한 두 부분의 답변이다.

셋째, 파일 작업 AI에 실제 답변 두 부분과 다음 세 파일을 함께 첨부한다.

- 두 시점 원본을 담은 `data/ulsan-two-quarters.zip`
- 공식 `data/industry-codes-2023.csv`
- `templates/ulsan-report-template.pptx`

ZIP을 읽지 못하는 도구에서는 압축을 풀어 두 원본CSV·코드표CSV·PPTX 양식의 네 파일을 첨부한다. API키 발급이나 학생의 수동 전처리는 기본 과정에 없다. AI가 두 원본 전체108,514행을 실제 파일 처리로 읽어 새XLSX와 수정 가능한5장PPTX를 제공하게 한다. 파일 지원이 없는 계정에서는 강사 예시로 결과 확인을 이어가되 직접 생성과 구분한다.

넷째, 두 결과를 다운로드하고 편집기로 열어 정리 결과·차트·5장 구성·출처·내용 일치를 확인한다. 제목 한 글자와 표의 내용을 실제로 수정해 본다. 원본은 그대로 두고 결과는 별도 이름으로 남긴다. 반복은 미래 파일을 가정하지 않고 같은 두 시점 자료에서 다른 공식 업종을 선택해 수행한다. 다른 대화나 도구로 옮기면 기준과 실행 요청, 실제 파일도 다시 전달한다.

## 분석과 해석의 경계

기본 보고는 구·군별 업종 분포, 공식 코드표에서 확인한 카페의 행정동별 분포, 두 시점 식별자의 계속 관측·새로 관측·미관측, 좌표 상태를 다룬다. 업종표는 코드로 연결하고 원본 이름과 코드표 이름을 각각 보존한다. 코드가 연결되어도 ‘보건의료’와 ‘보건의료업’처럼 이름이 다를 수 있다. 이름을 같게 만들기 위해 원본을 덮어쓰지 않는다.

행정동과 법정동, 상권업종과 표준산업분류는 구분한다. 두 파일에서 새로 관측되거나 사라진 식별자를 실제 개업·폐업 건수로 확정하지 않는다. 도로명주소가 같은 식별자에도 좌표 변경이 나타나므로 좌표 차이를 곧바로 이전이라고 표현하지 않는다. 이 데이터에는 매출과 실제 영업 사건을 입증할 필드가 없고 원인을 설명하는 별도 조사도 없다.

## 예시·화면·이전 자료의 상태

`examples/ulsan-summary.xlsx`와 `examples/ulsan-report.pptx`는 별도 제작 도구(artifact-tool)로 만든 강사 검토 예시다. 실제 원본 전체에 근거하지만 ChatGPT가 이번 실행에서 만든 파일이라고 주장하지 않는다. 실제 외부AI에서도13개 시트XLSX와5장PPTX가 생성되어 내려받았다. 분류명 차이 설명 두 곳을 실제 추가 요청으로 수정한 v2는 actual-run/에 별도 제공한다. 주요 수치800개 대조와 기존 수식 캐시2,193개·차트4개 보존,5장·편집표6개를 확인했다. 실제 Office에서 파일을 열었고 PPT 제목을 수정한 뒤 되돌렸다.

이번 실제 자료의 화면은 `content/automation-public-data-captures.json`으로 관리한다. 새 실제 화면이 없으면 기본 단계에 가짜 화면을 만들거나 이전 화면을 대체 표시하지 않는다. 이전 `automation-captures.json`의 가상사례 화면은 닫힌 ‘이전 가상사례 화면 참고’에 남긴다.

이전 가상 교육사업72문서, 회차별1만행 예제,8행 원리 모형, AGENTS·CLAUDE·폴더·PPT 참고는 접힌 선택 자료다. 기존 교재PDF와Office·데이터 원본, 저장된 작업은 보존하며 새 실제 수업을 완료한 증거로 승계하지 않는다.

## 로컬 검증과 남은 확인

전체CSV 파싱과 출처 해시, 업종표 계층·연결·이름 차이, 시점별 식별자 보존 관계, ZIP 내부 원본 일치, 공식 가이드 본문 보존을 검사했다. 강사 예시는XLSX3시트·PPTX5장과 실제 텍스트 객체를 확인했다. 기본4단계와 접힌 참고, 다운로드 경로, 셀·수식·답안폼 없는 진입도 검사했다.

최종 로컬 `npm test`는49개 모두 통과, 건너뜀0, 실패0이다. 구조 검사도 통과했다. 저장소에 포함된 공개 참고파일로 테스트하며 로컬artifacts가 없어도 실행할 수 있도록 수정했다. 실제 캡처14장의 SHA·크기·단계 연결을 검증했다. 기본 화면의 복사와 원본 항목 전환, 사진 확대·Escape 닫기, 새 원리 도식3종의 선택 동작,390px 모바일과1280px 화면의 가로 넘침 없음, 발표 양식 다운로드와 지침 HTML의 폴더 설명 직접 열기를 확인했다. 강사 예시 XLSX는 실제 Excel에서,5장 PPTX는 실제 PowerPoint에서 열었고 제목을 개별 텍스트 객체로 선택했다. 외부AI 생성물의 다운로드·열기·제목 수정과 주요 수치 대조는 확인했다. 학생 계정의 동시 실습·180분 완수·시간절감 효과와 공개 배포 상태는 별도 확인 범위로 구분한다.

## 재생성 경로

학생은 웹의 단계별 다운로드와 복사 버튼으로 진행한다. 아래 명령은 강사·유지관리자용이다.

- `python scripts/build-public-data-course.py`: 공개 저장소에 보존한 원본 CSV와 출처 해시로 전체 집계를 재생성한다. 수집 캐시가 있으면 전국 ZIP의 울산 멤버를 다시 추출한다. 카페는 이름 검색 대신 공식 소분류 코드 I21201로 계산한다.
- `python scripts/build-public-data-references.py`: 보존한 공식 메타데이터·원본 가이드·충실 추출문·코드표로 통합 TXT와 HTML을 만든다. 수집 캐시가 없어도 고정 해시를 검증한 공개 원본으로 재생성한다.
- `python scripts/build-public-data-pack.py`: 현재 요청문, 전체 원본, 기준, 양식, 예시와 실제 화면을 모아 별도 ZIP과 오프라인 웹 안내를 만든다.
- `node scripts/build-public-data-examples.mjs`: Codex 번들 artifact-tool·프레젠테이션 도구가 있는 강사 환경에서 예시를 다시 만든다. 필요하면 `CODEX_ARTIFACT_RUNTIME`과 `CODEX_PRESENTATIONS_SKILL`에 현재 번들 경로를 지정한다. 일반 수강생이나 CI 빌드에는 이 제작 환경이 필요하지 않다.

공식 전국 ZIP의 다운로드 주소·원본 멤버 이름·기준일은 공개 provenance.json에 보존했다. 약349MB·344MB 전국 배포본 대신 울산 원본 두 개를 변경 없이 공개하므로 다른 지역을 받지 않고 수업을 시작할 수 있다. 원본 코드표 CP949와 기존 README 바이트는 줄바꿈 정규화 대상에서 제외했다.
