# 중급반 · 다중문서 근거와 엑셀·PPT 반복 업무

2026-11-06 현재 웹 교재는 여러 기준·개정·예외 문서에서 적용 근거를 찾고 회차별 1만 행의 집계와 보고 파일을 만드는 흐름이다. 공개 주소의 `#automation?course=intermediate&unit=rag&focus=documents`에서 문서 자료실로 바로 간다.

## 수업의 실제 작업

1. 필요한 업무 요청을 선택한다. 문서ID·버전·시행일·상태·적용 범위를 확인한다.
2. 통합 TXT/PDF 또는 핵심 개별 문서를 외부 AI에 실제 등록한다. 웹의 선택은 외부 AI에 전송되지 않는다.
3. 원문 인용에서 조건을 확인하고 `work/evidence.txt`를 계산 도구로 전달한다.
4. 회차 XLSX 전체를 처리하고 채택·제외·보류, 두 지표의 분자·분모, 프로그램 합계를 검산한다.
5. 검산한 엑셀과 양식으로 5장 PPTX를 만들고 실제 객체 편집·숫자·출처·잘림을 확인한다.
6. 새 회차 파일과 변경 공문을 전달해 같은 절차를 재사용하고 하위 산출물을 갱신한다.

자기판단 입력·답안 비교·예측 퀴즈·별도 시간/오류 기록폼은 사용자의 지시에 따라 제공하지 않는다. 자료실은 자료 탐색·실행 프롬프트·실제 다운로드·산출물 확인 중심이다. 기존 단원 메모와 체크 기록은 보존한다.

## 구성과 시간

- 1교시50분: 목적10 / 폴더10 / 지침10 / RAG20.
- 2교시50분: 정리15 / 수식20 / 차트15.
- 3교시50분: PPT20 / 검증15 / 반복15.
- 휴식20분·마무리10분을 더해180분 편성이다. 실제 수업에서 완수 시간을 측정한 결과는 아니다.
- 본수업은 업무 요청 두 개를 다루며 전체 문서 강독은 요구하지 않는다. 나머지는 필요할 때 탐색한다.

## 문서 묶음

`content/reference-corpus.json`이 문서·업무 요청·원문 매핑의 원천이다. `scripts/build-reference-corpus.py`와 추가 상세 사례 JSON으로 개별 TXT/HTML, 통합 TXT/HTML/PDF, 목차, 실행 요청, manifest와 문서 ZIP을 생성한다. 자료는 강사 제작 가상 교육사업 문서이며 실제 기관의 정책·공문·실적이 아니다.

현재 적용·과거 보관·시행 예정·미채택·참고 상태를 구분한다. 본실습 산술은 B01에 그대로 수록한 운영 기준v2.0이다. R01/R02의 기존1만행 데이터와 검산 수치를 변경하지 않는다. 후속 공문은 보고 명칭·근거 표기 등 별도 범위를 명시한다. 과거 보고 숫자를 새 회차의 실제 처리 결과로 복사하지 않는다.

기존 실제 기관 문서 자료실과 가상 운영 기준의 역할은 별개다. 실제 법령·편람을 이 가상 참가자 집계의 사업 기준으로 재해석하지 않는다. HTML은 웹에서 열어 읽고 오프라인은 ZIP의 목차와 문서 폴더를 함께 보존한다.

## 원리 그림

`PrincipleLab`은10개 단원에 각각 입력→변환→출력을 보인다. 같은 별도8행에서 자료번호·정규화ID·근거절·판정·지표 기여·모형 집계 셀·PPT 표시를 연결한다.

- 원문 구절 선택과 확인 상태에서 계산 조건으로 넘어가는 RAG 경로.
- 지침·근거·입력 역할, 로컬 경로 탐색/CLAUDE 참조/웹 첨부 경계의 차이.
- 원본행 정규화·회차+ID 중복·채택/제외/보류와 신청·참여·응답 기여.
- 유효응답/참여전체 분모 비교, 새 행과 참조 범위, 수식·계산·표시의 차이.
- 같은 집계값의 축 변경, PPT 객체/통이미지 편집과 수치 불일치 경고.
- 원문→행→셀→PPT의 실제 불일치를 바로 수정하고 변경 영향을 재계산.

8행 모형은 채택5/제외2/보류1, 참여4, 유효응답2, 점수합8, 평균4.00, 참여율80.0%다. CSV와 판정 JSON을 받는다. 모형의 B2:B7은 실제1만행 파일의 B5:B15와 다른 예시 셀이다. 48행 준비·1만행 본실습·10만행 확장과도 구분한다.

확대는 하나의 컴포넌트 인스턴스를 유지하여 행·분모·회차·편집 상태를 보존한다. Escape·닫기·키보드 포커스 순환·스크롤 복원을 지원한다. 모바일 행 선택 후 상세로 이동한다. 본실습 전체 판정과 실제 회차 차트는 별도 펼침에서 볼 수 있다.

## PPT 참고 안내

공식 자료11개와7개 디자인 원칙을 유지한다. 색 비교는 같은3개 프로그램·0~4000명 축에서 범주명/직접 레이블만 바꾼다. 정렬은 한 장 안의 시작선, 글자 크기는 같은 내용·서체·색에서 본문 크기 차이에 한정한다. 스킬·라이브러리·자산·PPTX/웹/PDF 출력과 이용 조건을 구분한다.

## 파일과 검증

기존 Office 원본과 완성 예시를 재생성하지 않는다. `scripts/integrate-reference-pack.py`는 문서 안내와 지침·실행 프롬프트를 통합하고 전체 ZIP을 새로 묶는다. 원본PDF와 기존회차파일은 동일 바이트를 보존한다. 기존 기본 교재 PDF는 이전 판본으로 안내한다.

검증은 단위검사,10단원/자료실 서버 렌더링,실제 링크·ZIP CRC·원문 인용·PDF 재열기/한글/렌더,PC/모바일 조작을 구분한다. 외부 AI의 학생계정·새 응답·네이티브 Office와 실제 수업 동시 사용은 검증 범위에 포함하지 않는다. 증거는 `artifacts/reference-course-2026-11-06/`와 문서 생성기의 증거 폴더에 보관한다.
