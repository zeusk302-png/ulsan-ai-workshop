# 중급반: RAG·지침 파일·엑셀·PPT 웹 교재

## 현재 수업과 이전 자료

현재 중급반의 주 수업 경로는 `#automation?course=intermediate&unit=purpose`이다. 기존 `#intermediate` 진입도 새 웹 교재를 표시한다. 초급반은 변경하지 않는다. 기존 중급의 문서 사례 세 개, 7단계 참고서, 원문, 2026-10-14 캡처와 기본 PDF v2.1은 참고 자료로 보존한다. 새 작업을 실행한 증거로 이전 캡처를 표시하지 않는다.

## 학습 목표와 시간

지침 파일과 작업 폴더를 구성하고, RAG로 계산 기준의 근거를 찾고, 엑셀 수식·집계·차트를 만든 후 PPT로 전달한다. 같은 절차를 다음 회차 자료에 적용하여 회차·분모·계산·슬라이드 숫자의 갱신을 확인한다.

| 교시 | 단원과 배정 | 합계 |
|---|---|---|
| 1 | 작업 환경 10 · 폴더 10 · 지침 15 · RAG 15 | 50분 |
| 2 | 데이터 정리 15 · 엑셀 계산 20 · 차트 15 | 50분 |
| 3 | PPT 20 · 검토 15 · 반복 실행 15 | 50분 |

휴식 10분 두 번과 마무리 10분을 합쳐 180분이다. 각 교시의 설명·시연과 직접 활동은 단원 안에 포함된다. 상세 읽기·문제 해결·도식 조작은 자습 시 반복해서 사용할 수 있으며 모든 문장의 강독 시간을 추가한 편성이 아니다. 실제 혼합반의 180분 완수는 별도 수업 검증이 필요하다.

## 웹만 보고 따라가기 위한 구조

각 단원은 문제 상황 → 필요한 이유 → 얻는 결과 → 세 개의 개념 → 작업 도식 → 판단표 → 필요한 파일 → 단계별 행동·예상 결과·실패 시 복귀 → 복사 요청 → 전후 비교 → 확인 항목 → 작업 메모로 구성한다.

도식은 장식 그림이 아니라 입력, 처리, 사람의 확인, 출력과 실패 지점을 설명한다. 폴더 선택, 지시·자료 구분, RAG 질문 범위, 오류 후보, 분모 비교, 검토 복귀, 회차 변경 등의 조작을 제공한다. 모든 새 도식은 설명용으로 표시하며 실제 서비스 화면·실행 결과와 구분한다.

도구별 경로도 나눈다. 로컬 에이전트는 압축 해제한 프로젝트 폴더를 열고 인식한 지침을 확인한다. 웹 AI는 필요한 지침·기준·원본 파일을 직접 첨부한다. 파일을 폴더에 두는 것만으로 웹 AI가 읽거나 외부 노트북의 RAG 소스로 등록되지는 않는다. 이 사이트는 외부 AI 도구를 자동 제어하지 않는다.

## 지침·자료·실행의 구분

- `AGENTS.md`: 프로젝트에서 유지할 목표·규칙·입력 위치·완료 기준. 에이전트를 여러 개 만드는 설정이 아니다.
- `CLAUDE.md`: Claude Code의 지침. 공통 규칙은 `@AGENTS.md`로 가져오는 예시를 제공한다. 최신 Claude Code의 AGENTS 지원과 버전·설정 차이를 구분한다.
- `README.md`: 사람이 읽는 준비·사용 안내.
- 업무 절차 문서: 이번 보고 작업의 입력·출력·검토 순서. 파일명만으로 자동 실행되지 않는다.
- 실행 프로그램: 반복 처리를 수행하는 별도 코드. 지침 문서와 자동 실행을 구분한다.

RAG는 지표의 정의·분모·제외 조건·근거 위치를 확인한다. 전체 데이터의 정규화·중복 판정은 도구에서 선형 순회로 수행하고, 엑셀의 행별 지표 수식과 요약 수식으로 계산 근거를 남긴다. 매 행마다 이전 모든 행을 다시 세는 확장 COUNTIF 방식은 대량 자료의 기본 처리법으로 쓰지 않는다. PPT의 숫자는 검토한 집계표와 대조하고, 설명은 지표 정의와 응답 범위를 넘지 않도록 확인한다.

## 자료 규모와 작업의 필요성

| 규모 | 역할 | 배우는 것 |
|---|---|---|
| 48행 | 선택 준비 연습, 약 5분 | 원본 행과 제외·보류·분모를 손으로 대조 |
| 회차별 1만 행 | 본 실습 | 전체 정리·중복 판정·그룹 집계·차트·PPT 연결 |
| 10회차 합계 10만 행 CSV | 선택 확장 | UTF-8 CSV 가져오기, 회차별 집계, 회차+ID 복합 키 |

대량 자료는 기존 48행의 반복 복사로 만들지 않는다. 고정 시드에서 프로그램별 구성·참여·점수 분포를 다르게 생성하고 ID 누락·후속 중복·공백·소문자·참여값 오류·만족도 빈값/문자/소수/범위 밖 값을 포함한다. 미리보기 몇 행으로 전체 처리를 확인했다고 하지 않고, 원본 전체 건수=채택+제외+보류와 지표별 분모·차트 합계를 검산한다.

데이터 크기는 자동화의 유용성을 체감하게 하는 조건이다. 수업에서는 크기와 함께 명확한 규칙·다양한 오류·분류·반복 실행·검증을 제공한다. 원문 전체를 대화창에 붙이거나 RAG에게 전체 행의 계산을 맡기는 방식은 사용하지 않는다. 10만 행은 주어진 계정의 파일 지원과 처리 시간을 확인하는 선택 활동이며 모든 계정의 완료를 보장하지 않는다.

## 자료와 검산

새 운영 기준·두 회차의 각 1만 행 데이터·엑셀·PPT 양식과 예시는 강사 제작 교육용 가상 자료이다. 기존 실제 사업의 운영 성과나 공식 보고 기준으로 표시하지 않는다. 예시 파일은 외부 AI의 새 응답을 증명하는 자료가 아니다.

| 항목 | 1회차 | 2회차 |
|---|---|---|
| 원본 / 채택 / 제외 / 보류 | 10000 / 9824 / 119 / 57 | 10000 / 9824 / 119 / 57 |
| 참여 / 채택 | 7509 / 9824 | 7677 / 9824 |
| 참여율 | 76.4% | 78.1% |
| 만족도 점수 합 / 유효 응답 | 27379 / 7181 | 27961 / 7340 |
| 만족도 평균 | 3.81 / 5 | 3.81 / 5 |

중복 ID의 후속 행과 ID 누락은 제외한다. Y/N 이외의 참여 값은 보류하여 참여율의 분자·분모에서 제외한다. 참여자의 만족도 공란·정수1~5가 아닌 값은 평균에서 제외하되 원래 값과 처리 사유를 보존한다. 실제 파일의 수식·표와 공개 검산표를 함께 확인한다.

## PPT 스킬·디자인·GitHub 참고 안내

`#automation?course=intermediate&unit=ppt&focus=resources`에서 자료실로 바로 이동한다. PPT 단원 헤더에서도 열 수 있다. 기본 실습20분과 전체3시간 편성은 유지한다. 설치가 필요 없는 Microsoft 공식 안내 하나와 디자인 원칙 두 개를 기존 PPT 제작에 적용하며, 나머지 자료 탐색은 참고·자습으로 제공한다.

11개 자료를 스킬·작업 절차, PPTX 파일 생성, 웹·Markdown 발표, 디자인·아이콘·글꼴로 분류한다. 각 자료에 관리 주체·선택 시점·적용 순서·출력·호환 한계·개별 이용 조건과 복사 요청을 제공한다. 이름·용도·출력으로 검색하고 원문·라이선스·예제·릴리스를 확인할 수 있다.

- 스킬: OpenAI Build skills, 현행 OpenAI Plugins 예제, Anthropic PPTX 공식 안내 위치.
- 파일 생성: PptxGenJS, python-pptx.
- 다른 발표 형식: Marp, reveal.js.
- 디자인·에셋: Microsoft 접근성 안내, Lucide, Google Fonts, Fontsource Noto Sans KR.

현재 openai/skills는 이전 자료로 안내되므로 현행 Plugins 예제를 소개한다. Anthropic PPTX의 개별 Proprietary 조건은 링크와 자체 설명으로 안내하고 스킬·스크립트·에셋 원문을 배포하지 않는다. Marp 기본PPTX는 이미지 기반이고 편집형은 실험 기능·추가 환경·재현성 제약이 있음을 설명한다. HTML·PDF·PPTX와 실제 요소 편집 가능성을 구분한다. 소프트웨어·개별 글꼴·아이콘의 이용 조건도 구분한다.

디자인 원칙은 메시지, 시각적 위계, 정렬, 한글·숫자 서체, 대비, 근거, 편집·읽기 순서의7가지다. 같은 검산값76.4%와3.81을 유지한 자체 웹 모형으로 전후를 비교하고 확대할 수 있다. 실제 서비스 화면·AI 실행 결과·실제 PPT 캡처로 표시하지 않는다. 원본1만 행은 엑셀에 남기고 발표에는 검산한 요약을 배치한다.

복사 브리프는 데이터 근거와 디자인 참고를 별도 구역으로 나눈다. 참고 예시의 수치·성과 문장을 실제 데이터로 옮기지 않고, README 읽기와 실행 완료를 구분한다. 출력은 기존 파일을 보존한 `round-01-report-refined.pptx`로 제안한다. 선택·적용 이유와 확인 결과는 기존 PPT 단원 메모에 남기며 새 필수 완료 기준이나 스킬 설치는 추가하지 않는다.

## 저장 호환

기존 `ulsan-ai-workroom-v1` 키와 여섯 사례의 작성 글·검토 기록을 유지한다. 1만 행 본 실습의 기록은 `intermediateVolume: {revision:'automation-volume-2026-11-06', units:{…}}`에 저장한다. 기존 48행의 `intermediateCourse` 메모·체크는 그대로 보존하고 내 작업함에서 이전 기록으로 표시한다. 각 단원은 메모와 확인 항목 세 개를 가진다. 기존 완료 기록을 새 수업의 완료로 승계하지 않는다. 전체 JSON 백업·가져오기와 TXT 내보내기에 새 기록을 포함한다.
