## 독립 브라우저 검증

OpenDesign verifier가 Edge의 데스크톱 1440×1000, 모바일 뷰포트 390×844에서 확인했습니다. 실제 스마트폰 실기기 검증은 아닙니다.

- 일차 선택, 실습 6개 이동, 샘플·프롬프트 표시, 자료 8개 다운로드.
- 결과물·프롬프트·체크 항목 저장 및 새로고침 복원.
- 결과물과 검토 항목 3개를 충족해야 완료 표시 가능.
- 작업함에서 해당 실습의 작업 탭으로 이동, 브라우저 뒤로 가기.
- JSON 백업 내보내기·가져오기, 잘못된 JSON 거부, 텍스트 내보내기.
- 기록 초기화의 취소와 확정 동작.
- 모바일 메뉴 열기·이동·닫기.
- 12개 화면의 가로 넘침 없음. 최종 로컬 실행에서 브라우저 콘솔·페이지 오류 없음.
- 흑백 기반 올리브·라임 디자인의 PC·모바일 화면 검토.

브라우저 테스트의 입력 답변은 저장 기능 검증용 임의 텍스트입니다. 답변의 업무상 정확성이나 수강생의 이해도를 자동 평가한 것은 아닙니다. 실제 외부 AI 서비스의 응답 품질·사용 한도·기관 로그인 가능 여부도 별도 확인 대상입니다.

재현 스크립트: `tests/browser-qa.cjs`. Playwright와 Edge가 필요합니다. 설치된 Playwright를 기본으로 사용하고 별도 번들은 `PLAYWRIGHT_MODULE` 환경 변수로 지정할 수 있습니다. 로컬 앱을 띄운 뒤 실행하세요. `QA_URL`로 대상 주소를 지정할 수 있습니다. 결과 JSON과 스크린샷은 추적하지 않는 `artifacts/`에 저장합니다.
