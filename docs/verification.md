## 공식 원문 실습판 · 최신 검증

개념 보강: `tests/concepts-qa.cjs`에서10분 개념6개와 하루30분 시간 배정 일치, 컨텍스트 상황3개 피드백, 목적 수정에 따른 요청 변경, 업무 요약TXT내용,1440/390폭 넘침 없음, 연결된 실습 이동·개념복귀·주소 새로고침을 확인했다. 개념 자료는AI요청/대화관리 공식 문서를 참고하고 이 워크숍의 원문 대조 사례로 구성했다.

- `npm test`:10개 통과. 공식 원문6개의 크기·해시·법령 시행일·실습 문서 범위, 공고 상충 수치 보존, 전체31개 실제 이미지의 SHA-256을 포함한다. 이전8개·13이미지 기록은 아래 역사적 검증이다.
- `npm run build`, `git diff --check` 통과. PDF 읽기 도구는 필요할 때 불러오는 별도 번들이다.
- 독립 검증: 전문TXT4개 읽기·검색·복사/다운로드·해시, 공고HWP·ZIP, 출처·게시일·미시행 표시, 이전 작업 보존,1440/390폭 가로 넘침 없음.
- 실제PDF 검증: 북구17쪽 전체에서4쪽 원본 렌더링·AI검색·150%확대; 편람383쪽 전체에서27쪽·253쪽 원본 렌더링·‘인계’ 전체 검색26개 쪽·검색 결과 이동. 파일 전송 요청 없음, 콘솔 오류 없음. 기본 브라우저PDF iframe이 표시되지 않아 로컬PDF.js 표시 방식으로 구현했다.
- 캡처18개 모두 사람이 열어 실제 내용·설명·계정 영역 제외 상태를 검토했다.253쪽 검색 화면은 원본 페이지 표시 완료 후 다시 캡처했다. 초기AI응답의 과장·쪽수·버전 오류는 화면을 수정하지 않고 설명에서 검토 지점으로 표시했다.
- 6개 실습의 상세 가이드·실제 갤러리·이미지 로드·확대 대화상자·Escape·모바일 보기와13개 이전 기초 캡처의 별도 보관을 확인했다.
- 기존 전체 UI 회귀 검증: 모든6개 경로·공식자료·프롬프트·전문TXT다운로드, 결과물/체크 완료조건·저장/새로고침, 작업함/뒤로가기, JSON내보내기·가져오기·잘못된백업 거부, 초기화취소, 모바일 메뉴·탭·작업함 통과.
- 재현 스크립트: `tests/official-library-qa.cjs`, `tests/walkthrough-qa.cjs`, `tests/browser-qa.cjs`. 실제 스마트폰 실기기·수강생 전체 계정의 무료 한도·AI답변 정확성을 보장하는 검증은 아니다.

## 독립 브라우저 검증

OpenDesign verifier가 Edge의 데스크톱 1440×1000, 모바일 뷰포트 390×844에서 확인했습니다. 실제 스마트폰 실기기 검증은 아닙니다.

- 일차 선택, 실습 6개 이동, 샘플·프롬프트 표시, 자료 8개 다운로드.
- 결과물·프롬프트·체크 항목 저장 및 새로고침 복원.
- 결과물과 검토 항목 3개를 충족해야 완료 표시 가능.
- 작업함에서 해당 실습의 작업 탭으로 이동, 브라우저 뒤로 가기.
- JSON 백업 내보내기·가져오기, 잘못된 JSON 거부, 텍스트 내보내기.
- 기록 초기화의 취소와 확정 동작.
- 모바일 메뉴 열기·이동·닫기.
- 12개 화면의 가로 넘침 없음. 최종 로컬 실행에서 브라우저 콘솔·페이지 오류 없음.
- 흑백 기반 올리브·라임 디자인의 PC·모바일 화면 검토.

브라우저 테스트의 입력 답변은 저장 기능 검증용 임의 텍스트입니다. 답변의 업무상 정확성이나 수강생의 이해도를 자동 평가한 것은 아닙니다. 실제 외부 AI 서비스의 응답 품질·사용 한도·기관 로그인 가능 여부도 별도 확인 대상입니다.

재현 스크립트: `tests/browser-qa.cjs`. Playwright와 Edge가 필요합니다. 설치된 Playwright를 기본으로 사용하고 별도 번들은 `PLAYWRIGHT_MODULE` 환경 변수로 지정할 수 있습니다. 로컬 앱을 띄운 뒤 실행하세요. `QA_URL`로 대상 주소를 지정할 수 있습니다. 결과 JSON과 스크린샷은 추적하지 않는 `artifacts/`에 저장합니다.
