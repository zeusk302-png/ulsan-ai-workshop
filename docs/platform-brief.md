# 플랫폼 작업 명세

## 사용자와 목적

울산대학교에서 진행하는 비전공 직장인 대상 AI 강의. 수강생이 강사의 안내를 따라 업무 문서를 만들고, 검토하고, 다시 쓸 프롬프트와 결과물을 가져가는 실습실.

## 디자인 맥락

사용자가 첨부한 강좌 개요의 명확한 흑백 정보 구조를 참고한다. 한국어 가독성, 차분한 교육용 화면, 분명한 단계와 넓은 작업 영역을 우선한다. 대학의 공식 로고·인증·공식 운영 주체를 임의로 표시하지 않는다. 디자인은 사용자가 지정한 GitHub OpenDesign 스킬의 정확한 출처를 확인하고 적용한다.

## 화면

1. 과정 홈: 학습 목표, 1·2일차 선택, 실습 진행률, 이어하기.
2. 실습 화면: 목표, 소요 시간, 짧은 개념, 단계별 진행, 샘플 자료, 프롬프트, 확인 항목, 결과 입력.
3. 내 작업함: 저장한 결과물, 재사용 프롬프트, 전체 내보내기와 명시적인 삭제 확인.
4. 강의 안내: 준비물, 도구 링크, 무료 사용 제한 시 대체 진행법, 자료 입력 주의사항.

## 기능

- 실습 자료 다운로드와 프롬프트 복사.
- 직접 작성한 결과와 완료 상태를 localStorage에 저장.
- 저장 위치가 현재 브라우저임을 명시하고 공용 PC에서는 내보내기 후 삭제하도록 안내.
- JSON 백업 내보내기·검증된 가져오기, 텍스트 결과 내보내기.
- 강사가 제시한 예시 답변은 수강생이 먼저 실습한 뒤 펼쳐 확인.
- AI 응답 생성은 외부 도구에서 수행. 사이트에서 실제 AI가 응답한 것처럼 표현하지 않음.
- GitHub Pages 하위 경로에서도 동작하는 상대 경로 사용.

## 검증 기준

- 하루 시간 합계 180분, 직접 실습 합계 120분.
- 모든 실습의 샘플·프롬프트·검토 항목·예시가 연결됨.
- 복사, 저장, 새로고침 복원, 완료 표시, 내보내기·가져오기 확인.
- 키보드 이동, 모바일 화면, 길어진 한국어 텍스트 확인.
- 배포 완료와 공개 URL 응답 확인 후 공개 완료로 보고.
