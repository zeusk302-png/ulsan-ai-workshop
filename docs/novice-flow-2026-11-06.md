# 처음 사용하는 사람을 위한 Notebook → ChatGPT 실무 동선

작성일: 2026-11-06. 이번 검토는 로컬 캡처 카탈로그와 실제 이미지 파일을 직접 읽은 결과다. 새 서비스 화면에는 접속하지 않았다. 새 `src` 파일을 수정하지 않았다.

## 수업의 기본 경로

처음부터 8개 문서를 골라 읽거나 계산식·셀 주소를 찾게 하지 않는다. **72문서가 들어 있는 통합 TXT 한 파일을 Notebook에 등록 → 필요한 기준을 물어보기 → 그 기준을 담은 다른 AI용 요청문 만들기 → ChatGPT에 실제 엑셀·PPT 양식을 첨부 → 파일 만들기·내려받기**를 한 번 완주한다. 기존 문서 자료실과 원리 모형은 나중에 필요할 때 펼치는 참고 자료로 둔다.

통합 TXT의 문서 수는 72개이지만 업로드 파일은 1개다. 따라서 Notebook의 소스 수가 1개여도 정상이다. TXT와 PDF를 모두 넣게 할 필요는 없다. 우선 `all-documents.txt` 한 파일로 진행하고, PDF는 읽기·대조용 대안으로 둔다. 소스 목록에서 72개 항목이 보이기를 요구하면 안 된다.

## 제안하는 기본 6단계

| 단계 | 수강생에게 보여줄 행동 | 다음에 보여야 할 것 | 막혔을 때 |
|---|---|---|---|
| 1. 전체 자료 준비 | `전체 문서 TXT 받기` 한 버튼으로 `all-documents.txt` 저장. 이어 `1회차 엑셀`·`발표 양식` 저장 | 내려받은 TXT·XLSX·PPTX 파일명 | ZIP 압축 해제와 72개 선택을 첫 과제로 만들지 않음. 통합 PDF는 대안으로만 제공 |
| 2. Notebook에 등록 | 새 Notebook에서 `+ 소스 추가`를 누르고 통합 TXT 업로드. 업로드 메뉴의 실제 명칭은 새 캡처에서 확인한 문구 사용 | 왼쪽 소스 목록에 통합 TXT 이름이 보이고 처리가 끝남 | 목록에 없으면 등록을 다시 진행. 텍스트 붙여넣기 대안은 모달에서 `삽입`까지 눌러야 함 |
| 3. 기준 물어보기 | 아래 요청 ①을 채팅에 붙여넣고 전송. 답변 인용 번호 하나를 눌러 원문 위치 보여주기 | 자료에 근거한 기준 정리와 원문 인용 | 엑셀 인원·평균을 이미 계산했다고 하면 ‘아직 엑셀은 주지 않았으니 기준만 정리’라고 요청 |
| 4. 실행 요청문 받기 | 같은 Notebook 채팅에서 요청 ② 전송. 나온 요청문을 복사 | 다른 AI에 바로 붙일 한 덩어리의 요청문 | 공문 설명만 길게 나오면 ‘설명은 빼고 복사할 작업 요청문만’이라고 요청 |
| 5. ChatGPT에서 파일 만들기 | 새 대화의 `+`에서 1회차 XLSX·발표 양식 첨부. 파일 이름이 보인 뒤 요청문과 요청 ③ 전송 | 첨부한 파일 표시와 생성된 XLSX·PPTX 파일 링크 | `+` 메뉴·파일 선택 항목은 새 캡처의 실제 라벨 사용. 목차만 나오면 아래 보완 요청을 전송 |
| 6. 내려받아 열기 | 결과의 XLSX·PPTX 링크를 각각 눌러 저장하고 열기. 2회차는 같은 대화에 새 원본 첨부 후 요청 ④ | 엑셀 요약·차트와 실제 5장 발표. 다음 회차 제목과 숫자가 새로 바뀜 | 다운로드 링크가 만료·실패하면 같은 대화에서 파일을 다시 생성해 달라고 요청. 파일 생성 기능이 제한되면 강사 제공 결과·양식을 열어 흐름을 이어감 |

기본 화면에는 퀴즈·자기판단·자가평가·수업 기록 폼이 필요 없다. `원문 보기`와 `파일 열기`는 실제 업무를 진행하기 위한 동작으로 설명한다. 수식·셀 주소·분모 용어는 기본 안내에 노출하지 않고, 필요한 계산 기준은 Notebook이 생성하는 실행 요청문 안에 담는다.

## 그대로 복사할 요청문

### ① Notebook: 전체 자료에서 기준 찾기

```text
등록한 통합 자료 전체를 읽고, 교육 프로그램 1회차의 엑셀 요약과 5장 발표자료를 만들 때 지켜야 할 기준을 찾아줘.

지금 적용할 기준과 이전·예정·참고 문서를 구분하고, 빠진 값·중복·참여 표시·만족도 응답을 어떻게 다루는지 쉬운 말로 정리해줘. 각 기준 옆에 문서 이름과 인용을 붙여줘.

아직 엑셀 파일은 첨부하지 않았으니 참여 인원이나 평균을 계산했다고 말하지 마. 자료에 없는 내용은 만들지 말고 확인할 내용으로 남겨줘.
```

### ② Notebook: ChatGPT로 넘길 실행 요청문 만들기

```text
방금 찾은 기준을 빠뜨리지 말고, ChatGPT에 그대로 붙여넣을 작업 요청문 하나로 만들어줘.

내가 별도로 첨부할 1회차 신청자료와 발표 양식을 사용해, 원본을 보존하면서 참여·만족도·프로그램별 현황을 정리한 엑셀 파일과 수정 가능한 5장 발표 파일을 만들도록 써줘.

적용 기준, 교육용 가상 자료 표시, 숫자와 출처 확인을 포함해줘. 엑셀과 PPT는 실제로 내려받을 수 있는 파일로 요청해줘. 답변에는 복사할 작업 요청문만 보여줘.
```

### ③ ChatGPT: 실제 파일 첨부 후 생성

Notebook에서 받은 요청문을 그대로 붙이고 아래 문장을 덧붙인다. 먼저 화면에서 XLSX와 PPTX의 실제 첨부 표시를 확인한다.

```text
첨부한 1회차 파일과 발표 양식을 사용해 위 요청대로 엑셀 요약 파일과 편집 가능한 5장 PPTX를 만들어줘. 원본은 변경하지 말고, 완성 파일을 내려받을 수 있게 제공해줘.
```

설명이나 슬라이드 목차만 나왔을 때:

```text
지금 받은 것은 설명과 목차야. 이 대화에서 실제로 내려받을 수 있는 XLSX와 PPTX 파일을 생성해줘. 파일을 만들 수 없다면 가능한 기능과 막힌 부분을 먼저 알려줘.
```

### ④ ChatGPT: 다음 회차로 반복

2회차 XLSX를 새로 첨부한 뒤 사용한다.

```text
이번에는 새로 첨부한 2회차 원본으로 같은 작업을 해줘. 앞서 확인한 기준과 발표 구성을 유지하고, 숫자는 새 원본으로 다시 계산해줘. 제목·회차·날짜·차트·출처를 2회차에 맞게 바꾸고 1회차 결과는 덮어쓰지 마. 2회차 XLSX와 PPTX를 각각 내려받을 수 있게 만들어줘.
```

## 새 촬영에서 꼭 필요한 장면

1. 통합 TXT/PDF를 선택하는 업로드 창과 실제 파일명.
2. 등록 완료 후 통합 자료 이름이 보이는 Notebook 목록. ‘72문서·소스 1개’ 관계를 캡션으로 설명.
3. 요청 ①과 실제 답변의 인용. 인용을 연 원문 상태.
4. 요청 ②에 대한 실제 실행 프롬프트와 복사 동작 위치.
5. ChatGPT `+` 메뉴→파일 선택→XLSX·PPTX 첨부 완료.
6. 실제 생성된 XLSX·PPTX 파일 링크. 링크를 눌러 내려받은 파일을 연 결과.

실행이 막히면 그 단계의 실제 상태를 기록한다. 생성되지 않은 파일이나 캡처하지 않은 메뉴를 완성 화면으로 꾸미지 않는다. 새 캡처에는 촬영일·서비스·사용 자료·완료 여부를 함께 남긴다.


## 구현 반영

기본 경로는 GuidedAutomation 네 단계이며 상세 참고는 처음에 마운트하지 않는다. 72문서 전체를 통합 TXT/PDF 하나로 올리고 실제 RAG 응답 두 부분을 원본·양식과 함께 넘긴다. 기본/상세 중급 교재의 검토 체크박스·메모 작성 폼·진도 계수는 제거했다. 기존 저장 데이터의 호환·백업 경로는 유지했다. 실제 캡처는 content/automation-captures.json에 촬영일·원본 서비스·가림 목적 자르기·해시·실제 치수와 함께 기록한다. 강사 예시 Office 화면은 현재 외부 AI 생성 결과와 명시적으로 구분한다.
