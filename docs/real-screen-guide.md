# 실제 화면 기반 실습 안내

작성·캡처일: 2026-10-14 (Asia/Seoul).

## 추가한 학습 내용

- 실습 6개에 각각 준비 사항, 최종 결과물, 5단계 행동과 확인 기준, 소요 시간.
- 짧은 요청과 구체적인 요청의 비교 6쌍.
- 복사 가능한 후속 요청 18개, 막혔을 때 해결법 18개.
- 조건을 바꾸는 선택 과제 6개와 마무리 질문 6개.
- 처음 사용자를 위한 핵심 개념 4개.
- 실제 화면 탭, 확대 모달, 모바일 전체 맞춤·읽기 확대, 원본 캡처 링크.

실습 시간은 변경하지 않았습니다. 기본 5단계의 시간 합계는 각 실습의 35·40·45분과 일치합니다. 혼자 해보기는 기본 실습 후 선택 과제이며 수업 분량에 추가로 강제되지 않습니다.

## 실제 캡처 범위

`content/screen-captures.json`에 13개 파일의 출처 도메인, 캡처 상태, 설명, 읽을 지점, 크기와 SHA-256을 기록했습니다. 실제 이미지 파일은 `public/screens/`에 있습니다.

| 도구 | 실제 수행한 작업 | 캡처 수 |
| --- | --- | --- |
| ChatGPT | 가상 일정 변경 메일 입력·생성·후속 수정, 재사용 보고 템플릿과 A·B 사례 적용 | 5 |
| Gemini | 가상 교육 안내문·보고서 요청과 결과, 회의 실행 목록 추출 | 4 |
| NotebookLM / 캡처 계정의 Gemini Notebook | 새 비공개 노트북에 가상 운영 지침·FAQ 추가, 두 소스로 질의응답, 인용 번호를 눌러 원문 확인 | 4 |

기존 개인 노트북이나 실제 고객 파일을 실습 자료로 사용하지 않았습니다. 새 실습 노트북은 별도 공유하지 않았으며 공개 사이트는 해당 비공개 노트북에 연결하지 않습니다.

화면을 HTML로 재현하거나 AI 이미지로 생성하지 않았습니다. 브라우저가 실제 표시한 화면을 캡처했습니다. 개인정보 영역은 캡처 범위에서 제외했습니다. 두 ChatGPT 템플릿 화면은 잘못된 위치를 반환하는 클립 캡처 대신 실제 뷰포트 원본을 저장한 후 왼쪽 계정 영역만 잘라 공개했습니다. 답변 문장·수치·버튼 내용은 수정하지 않았습니다. 보존한 뷰포트 원본은 추적하지 않는 `artifacts/capture-originals/`에 있습니다.

## 실제 응답과 정답의 구분

- 기존 “강사 예시”는 강사가 작성한 예시로 유지했습니다.
- 새 “실제 실행 캡처”는 도구가 실제 생성한 결과입니다. 정답이나 보편적 화면 구성을 보증하지 않습니다.
- Gemini 보고서에는 원문에서 확정하지 않은 지참 독려 계획이 추가되어, 삭제하거나 제안으로 분리하는 검토 대상으로 안내합니다.
- Gemini 회의 정리에는 표 중복과 현황·결정 분류 문제가 보여, 중복 정리와 원문 대조 대상으로 안내합니다.
- Notebook 자동 요약의 정원·참석 인원 표현 차이를 원문 대조 대상으로 안내합니다.

## 계정·화면 차이

캡처 계정에는 Pro 등 유료 기능 표시가 있을 수 있습니다. 학습에는 텍스트 입력·수정·복사와 제공 문서 질의응답만 요구하며, 해당 모델이나 유료 기능을 선택하도록 안내하지 않습니다. 무료 플랜의 실제 제공 범위·한도와 기관 계정 접근 여부는 수강생 환경에서 달라질 수 있습니다.

캡처 계정에서 NotebookLM 주소가 Gemini Notebook 화면으로 연결되었습니다. 이를 모든 계정의 일괄 변경으로 단정하지 않고, 현재 캡처에 나타난 이름으로만 설명합니다.

## 검증

`npm test`에서 상세 가이드 구성, 시간 합계, 이미지 13개 존재·JPEG 형식·SHA-256 일치, 복합 프롬프트의 샘플 삽입을 검증합니다. 독립 검수자가 각 캡처의 내용·설명 일치와 개인 정보 노출 여부를 확인합니다.

브라우저 재현: `tests/walkthrough-qa.cjs`. 가이드 6개, 이미지 로드, 4개 탭, 확대창·Escape·포커스 복귀, 긴 안내에서 자료 탭으로 이동, 모바일 가로 넘침 등을 검사합니다. 실제 스마트폰 실기기 또는 수강생 이해도 검증을 뜻하지 않습니다.

프롬프트 기본 안내의 참고: [OpenAI 공식 문서](https://learn.chatgpt.com/docs/prompting). 구체적인 실습 자료·설명·검토 기준은 이 강의를 위해 작성했습니다.
