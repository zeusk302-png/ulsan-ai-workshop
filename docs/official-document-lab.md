PDF는 비어 있지 않은 자연 줄, 법령은 조문·부칙 단락을 센다. PDF 페이지 표식과 빈 줄은 분량에 넣지 않는다. HWP·법령의 원본 쪽수는 확인하지 않아 표시하지 않는다. HWP 텍스트는 제어코드를 제거한 전문이며 표 배치·빈 서식·별표는 원본으로 대조한다. 법령TXT는 연결된 별표 이미지나 서식 첨부를 포함하지 않는다.

법령TXT의 맨 앞에는 국가법령정보센터 원문 제목·시행일·공포 정보를 그대로 포함한다. 첫 실습에서 제목·버전 헤더 없는 추출문과 편람의 옛 조문이 혼동된 사례를 발견해 원문 헤더를 보존하도록 보완했다. 본문 단락 수에는 이 식별용 헤더를 더하지 않는다.

출처·다운로드 URL·공포/게시일·시행 표시·수집일·원본 및 추출문 SHA-256은 `content/official-documents.json`에 기록한다. 원문을 바꾸거나 빈 줄을 늘리지 않는다. 편람·업무계획 전체 PDF는 발행기관 직접 다운로드 링크로 제공한다. 공고HWP와 법령·공고 전문TXT는 사이트에도 제공한다. 전체 기관 편람·업무계획의 재배포 허락을 추정하지 않고 원본 제공기관 링크를 사용한다. 로컬 `materials/`에는 테스트에 사용한 전체 원본을 보존하며 공개 저장소에서 제외한다.

## 학습 범위

기본5개: 편람PDF, 업무계획PDF, noticeTXT, regulationTXT, rulesTXT. 총PDF400쪽과 공고·법령 전문을 실제 노트북에 등록했다. 계정의 화면명은 Gemini Notebook으로 표시됐으며 다른 계정의 일반 NotebookLM 화면과 명칭·메뉴가 다를 수 있다.

민원법 자료는2026-06-02공포·2026-12-03시행예정본이다. 수집일에는 시행 전이므로 기본 질문에 섞지 않고 버전 비교에만 사용한다. 중구 공고의 접수기간과 북구 업무계획 기간은 과거 일정이며 교육용 독해 대상으로 명시한다.

## 원문 대조 사례

- 중구 공고: 사업개요12,000천원과5.가12,000원; 본문 재료비130,000원과붙임2서식150,000원이 다르다. 어느 쪽이 옳다고 결정하지 않고 두 원문을 병기한 확인 질문으로 전환한다.
- 북구 업무계획: 미디어정보과AI교육은 실제PDF뷰어4쪽·인쇄쪽수-2/15-에2.24.15:00~10:00으로 표시되어 있다. PDF이미지와 추출문 모두 직접 확인했다. 올바른 종료시간을 추정하지 않는다.
- 실제AI응답은 “우편·온라인 불가”, “즉시 제외”, “단위 오기 추정”을 추가했고17쪽PDF의 “18쪽”을 근거로 제시했다. 첫 답변과 후속 수정 화면을 그대로 보존하며 검토 대상으로 표시한다. 캡처의 응답은 검증된 모범답안이 아니다.
- 계획은 완료 증거가 아니며, 담당부서는 개인 담당자와 다르다. 전체 융자규모170억원과업체당2억원은 범위가 다른 수치다.

## 실제 캡처

공식 게시물2개와 전체 원문 등록·조건 추출·메일·FAQ·보고·수정·업무계획·편람·다중 소스·인용·템플릿 시험 화면을 실제 연결된 Chrome에서 캡처한다. `scripts/prepare-official-captures.py`는 계정 영역만 잘라 공개한다. UI·답변 내용은 수정하거나 재구성하지 않는다. 이전13개 가상 기초 캡처는 시작 안내의 접힌 별도 갤러리에 유지한다.

## 수강생 결과물

PDF 원본은 다운로드 후 사이트의 로컬PDF 읽기 도구로 열 수 있다. Mozilla PDF.js로 실제 페이지를 표시하고 전체 본문 검색·쪽수 이동·150/200%확대를 제공한다. 파일은 브라우저에서만 읽고 서버나AI에 전송하지 않는다. 실제 편람383쪽에서 ‘인계’ 검색을 완료해26개 쪽을 찾았으며17쪽 업무계획의4쪽 원문도 확인했다.

각 실습에서 전체 원본 파일을 등록하고 원문 위치·근거 문장·확인 필요를 결과와 함께 저장한다. JSON백업은 기존 작업을 유지한다. 전체 문서를 도구 한도로 분석하지 못하면 분석한 범위를 기록하며 요약 미리보기를 전체 원문처럼 취급하지 않는다.
