# 2026-11-04 수업 시각화 보강

범위: 작업 흐름의 정보 구조화, RAG 근거 연결, 컨텍스트 관리 화면. 현재 공개 화면을 직접 캡처한 뒤 같은 작업의 로컬 수정 화면과 비교했다. 기존 Workroom 색상·글꼴·탐색 구조를 유지한다.

| 화면 | 관찰한 문제 | 반영한 변화 | 현재 상태 |
|---|---|---|---|
| 1. 정보 구조화 | 상자마다 설명만 있어 원문이 결과로 바뀌는 모습이 보이지 않음 | 실제 업무계획의 원문 발췌와 분류표·초안·주장 검토를 병렬 배치. 두 항목과 세 결과 표현 전환 | PC·모바일 선택과 내용 전환 확인 |
| 2. RAG | 단계 이름과 입출력 설명은 있으나 소스·근거 문장·주장이 분리됨 | 등록 자료 → 질문별 선택 → 근거 후보 → 주장과 판정 연결. 문서 형식·사업 금액 사례 선택, 근거 TXT 연결 | 소스 3/1개 선택과 근거 1/2개 전환 확인 |

홈에는 실제 자료의 발췌 → 정리 결과 미리보기를 넣고 대응 단계로 연결한다. 목적 단계에는 사람/AI/작업물의 작업 분담표를 제공한다. 실제 캡처는 전체 폭으로 크게 보여주고 화면 선택·원본 열기·기존 확대 갤러리를 유지한다. 단계 주소로 진입하면 PC에서도 해당 본문으로 이동하며 전체 흐름 복귀를 제공한다.

자료와 해석의 경계: `src/visual-examples.js`의 인용은 보존한 공식 문서와 대조한다. 분류·초안·오류 예는 강사 구성이고 새 AI 실행 결과가 아니다. 과거 계획을 현재 모집·완료 사실로 표시하지 않으며 공고의 상충 금액은 미결로 유지한다. 일반 RAG 설명도는 특정 서비스의 내부 실행·검색 순위 재현이 아니다.

구현: `src/LearningVisuals.jsx`, `src/learning-visuals.css`, `src/visual-examples.js`. 기존 교재·원문·캡처·저장 스키마·반별 시간표에는 변경 없음.
