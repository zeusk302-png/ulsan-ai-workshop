# [1. 적용할 기준과 주의사항]

* **수치 미확정 안내**: 2026년 6월·9월 울산 점포 원본 CSV 파일(`ulsan-two-quarters.zip`)은 아직 전달받지 않은 상태이므로, 본 단계에서는 최종 집계 수치 계산이나 파일 생성을 진행하지 않고 지침 정립에 집중합니다.

### 2. 공식 출처 자료와 강사 요구사항의 명확한 구분
* **공식 원문 및 근거 위치**:

  * **P02 (공식 OpenAPI 활용가이드 HWP, 2026.7 표지 / 260805)**: 소상공인 상권업종분류 체계(대분류 2자리, 중분류 4자리, 소분류 6자리) 및 REST API 명세.
  * **P03 (공식 API 39개 항목 설명 및 실제 CSV 대응표)**: `bizesId`(상가업소번호, 20자리 텍스트), `adongCd`/`adongNm`(행정동 코드/명), `ldongCd`/`ldongNm`(법정동 코드/명), `lon`/`lat`(경도/위도) 등 정의 및 부록 울산 구·군 코드(31110 중구, 31140 남구, 31170 동구, 31200 북구, 31710 울주군).
  * **P04 (공식 2023 상권업종 코드표, 2023-02-28 기준 / 2025-08-26 포털 수정)**: 247행 (대10·중75·소247), CP949 인코딩.

### 3. 업종코드 및 업종 이름 처리 기준
* **소분류 코드 결합**: 2023 공식 상권업종 코드표(P04, 247행)의 6자리 `소분류코드`를 키로 하여 2026년 6월/9월 원본 CSV의 `상권업종소분류코드`(`indsSclsCd`)와 대조합니다.
* **명칭 버전 차이 보존 (P04 s4, P05 s3)**: 2026 원본 CSV의 업종명과 2023 코드표의 업종명 간 버전 차이가 존재하므로, 원본 CSV의 업종 이름을 덮어쓰지 않고 원본 명칭과 2023 코드표 명칭을 각각 별도 열로 보존합니다.
* **관심 소분류(카페) 추출 방식 (P05 s3, P06 s3)**: 상호명 텍스트 검색(예: '카페' 단어 검색)으로 대체하지 않고, 코드표 상의 비알코올 음료점업 내 카페 소분류 코드(`I21201`)를 기준으로 필터링합니다.

### 4. 행정동과 법정동의 명확한 구분
* **행정동(`adongCd`, `adongNm`)**은 주민 행정 관리 단위이며, **법정동(`ldongCd`, `ldongNm`)**은 법정 구역 단위로 서로 별개의 개념입니다 (P03 s2, P05 s2).
* 동 이름이 같다고 해서 두 단위를 임의로 혼용하거나 결합하지 않으며, 본 보고서의 지역 동별 분석은 행정동을 기준으로 명확히 구분하여 집계합니다.

### 5. 두 시점 자료의 의미 및 관찰 상태 구분
* 2026년 6월 30일(54,737건)과 9월 30일(53,777건)의 공공데이터 포털 공개 스냅샷 데이터로, 두 시점 전체 원본 레코드는 총 108,514건입니다 (P01 s2/s4/s7, P06 s1). 이는 108,514개의 서로 다른 고유 업소를 의미하지 않습니다.
* 두 분기 CSV의 `상가업소번호`(`bizesId`, 20자리 텍스트 식별자)를 대조하여 **1) 양쪽 모두 관찰**, **2) 9월에만 관찰(현재만)**, **3) 6월에만 관찰(이전만)**의 3가지 상태로 구분합니다 (P05 s5).

### 6. 좌표의 의미, 설명 충돌 및 데이터 한계
* **좌표 체계**: WGS84 좌표계 기준 경도(`lon`, 울산 약 129°) 및 위도(`lat`, 울산 약 35°)입니다 (P03 s2/s4).
* **공식 Swagger 설명 충돌 (P03 s2, P05 s7)**: 공식 가이드 Swagger 명세에 `lon`과 `lat` 설명이 모두 'WGS84기준 위도 좌표값'으로 표기되어 있으나 원문을 수정하지 않고, 실제 헤더 및 수치 범위를 대조하여 경도(가로축)와 위도(세로축)로 판단합니다.
* **좌표 변경 상태 (P05 s6)**: 두 시점 모두 관찰된 업소 중 1,223개는 도로명주소가 동일함에도 경도/위도 좌표 수치가 달라졌습니다. 이는 실제 업소의 물리적 이전으로 단정할 수 없으며 좌표 정비 등 불명확한 원인이 있을 수 있음을 명시합니다.
* **자료의 결정적 한계 (P05 s8)**: 제공된 원본 데이터에는 매출, 이익, 유동인구, 실제 개업일·폐업일 사건 기록, 주민등록인구 분모 등이 포함되어 있지 않습니다.
* **금지 사항**: 매출 발생, 영업 성과, 실제 개업·폐업·이전 행정 사건, 인구 1천 명당 업소 수 등을 본 자료만으로 입증된 사실처럼 주장하거나 단정하지 않습니다.
