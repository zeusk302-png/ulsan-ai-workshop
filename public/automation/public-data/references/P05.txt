s1 공식 사실과 강사 분석 지시의 구분
이 문서의 절차는 수업용 분석 방법이다. 공식 원문은 P01~P04에 보존했고 원문과 충돌하는 설명을 조용히 수정하지 않는다. 실제 CSV의 열·값·기준일과 공식 설명을 함께 읽는다. RAG는 정의와 주의사항을 찾아 실행 요청에 포함하는 역할이고 전체 108,514 레코드의 집계는 실제 파일을 읽는 계산 도구의 역할이다. 문서가 길거나 인용이 붙었다는 사실은 전체 데이터 계산의 완료 증거가 아니다.

s2 인코딩·식별자·지역·분류의 처리
두 상가 CSV는 UTF-8로 읽고 코드표는 CP949로 읽는다. CSV를 더블 클릭했을 때 한글이 깨졌다고 원본 파일이 손상됐다고 단정하지 않는다. 분석 AI가 각각 인코딩을 지정하고 실제 39개/6개 열과 한글을 확인한다. 상가업소번호·지역 코드·업종 코드·우편 번호·건물 관리 번호는 텍스트로 보존한다. 같은 상호나 주소만으로 행을 중복 제거하지 않는다. 식별번호 중복이 있다면 동일·상이 열과 출처를 확인한 뒤 처리 근거를 남긴다. 가상 참가자 실습의 첫 행 채택·누락 수·참여 Y/N 조건을 실제 상가에 적용하지 않는다. 행정동과 법정동은 별개이며 동명만으로 결합하지 않는다.

s3 코드와 이름을 조인하는 순서
코드표 소분류 코드가 유일한지 확인 →두 분기의 소분류 코드를 텍스트로 대조 →미매칭을 별도 표시 →2023 참조 이름을 새 열로 추가 →조인 전후 행 수 검산 순서다. 2026CSV의 원문 이름은 보존한다. 모든 행에 이름 차이가 있어도 삭제하거나 기준 숫자에 맞춰 이름을 덮어쓰지 않는다. 대·중·소분류 코드를 함께 보관해 상하위 관계를 검토한다. 표준 산업 분류와 상권업종을 임의로 같은 키로 쓰지 않는다. 분석 결과에서는 선택한 표시 명칭의 버전을 밝힌다.

s4 분포 지표와 분모
구군 업소 수와 구군의 울산 전체 비중, 구군 내부 업종 구성비, 선택 업종의 동별 수와 해당 동 전체 업소 대비 비중은 서로 다른 지표다. 이름이 모두 비중이라도 분모를 구체적으로 적는다. 업소 기록은 사람 수가 아니며 두 분기 레코드 합은 고유 업소 수가 아니다. 구군별 합 =해당 분기 전체, 구군 × 업종 합 =해당 분기 전체, 선택 업종 동별 합 =해당 분기 선택 업종 전체를 같은 필터·미확인 처리로 대조한다. 상호 명에 특정 단어가 있다는 이유로 업종을 정의하지 않고 코드표의 소분류를 확인한다.

s5 신규 관찰·미관찰과 개업·폐업의 차이
두 분기의 상가업소번호를 연결한 뒤 양쪽 관찰·현재에만 관찰·이전에만 관찰을 구분한다. 이 상태는 공개 스냅샷의 관찰 여부이며 신규 개업·폐업이라는 행정 사건을 직접 증명하지 않는다. 수집·정비·포함 범위·분류 변경의 영향을 배제할 자료가 없으므로 개업률·폐업률·생존율을 단정하지 않는다. 현재에만 관찰된 레코드 수는 9월 전체 −양쪽 관찰, 이전에만 관찰된 수는 6월 전체 −양쪽 관찰로 검산한다. 지역·업종별 증감은 원인 분석이 아니라 관찰 수의 차이로 표현한다.

s6 좌표 차이와 주소 불변을 함께 읽기
양쪽에서 관찰되는 식별번호 중 1,223개는 경도·위도문자열이 달라졌지만 도로명 주소 문자열은 같다. 이를 1,223건의 업소 이전이라고 부르지 않는다. 위치 정비 등 다른 이유가 있을 수 있고 실제 이유는 확인하지 못했다. 좌표를 숫자로 비교할 때 문자 표현 차이와 수치 차이도 구분한다. 지도는 제공 좌표의 분포를 보여 주는 보조 표현이며 현장 위치·영업 상태의 검증이 아니다. 좌표가 없는 행이 발견되면 지도 표현과 일반 지역 집계의 처리 영향을 분리한다.

s7 공식 문서 내부의 다른 시점과 설명
전국 ZIP README의 8개 과거 대분류와 현재 포털/CSV의 10개 분류, 가이드의 분기 갱신 안내와 API 카탈로그의 실시간 안내, Swagger에서 lon/lat 설명이 모두 위도인 문제를 각각 출처별로 기록한다. 한 문서를 새로운 통일 규칙으로 고쳐 전체에 적용하지 않는다. 현재 분석은 6월 말·9월 말 파일 스냅샷이며 실시간 조회 완료라고 쓰지 않는다. 공식 출처라는 이유만으로 서로 다른 자료의 설명이 모두 일치한다고 가정하지 않는다.

s8 데이터가 없는 지표와 해석
제공된 파일에는 매출·이익·방문객·유동 인구·공실·폐업 사건·영업 시간·주민 등록 인구 분모가 없다. 인구 1 천 명당 업소 수, 수익성, 창업 성공 가능성, 좋은 입지를 계산했다고 쓰지 않는다. 업소가 많거나 특정 업종 비중이 높다는 관찰은 보고할 수 있지만 수요·경쟁 강도·수익의 확정 판정과 다르다. 인구 자료를 별도로 얻는 후속 분석은 같은 지역 단위·기준 시점·코드·대상 범위를 확인해야하며 현재 제공 과제의 필수 입력이 아니다.

s9 파일 생성·검토의 완료 범위
XLSX와 PPTX 실제 파일 다운로드를 받고 열어 본다. 설명·목차·코드만 받은 상태는 파일 생성 완료가 아니다. 제목 한 글자와 표 내용 하나를 고쳐 개별 편집 요소인지 확인한다. 차트/ 지도 이미지와 원본 데이터 차트의 편집 범위를 구분한다. 엑셀과 PPT 의회차·단위·분모·숫자·출처가 일치하는지 파일 작업 AI와 실제 편집 화면에서 확인한다. 지원하지 못한 계산·생성·표시 검증은 미수행으로 남긴다.
