P06 | 울산 두 분기 실제 상가자료로 만드는 지역·업종 보고
성격: 강사 작성 수업 과제·실행 요청 / 공식 기관의 보고 지침 아님
버전: 2026-11-06
출처ID: sbiz-file-202606, sbiz-file-202609, sbiz-industry-2023, sbiz-api-guide

s1 업무와 실제 입력
업무는“울산의 어느 구군과 행정동에 어떤 업종이 분포하며 두 분기에 관찰 구성이 어떻게 달라졌는가”를 설명하는 지역 브리핑이다. 원본은 ulsan-202606.csv 전체 54,737행과 ulsan-202609.csv 전체 53,777행이며 두 파일 모두 39열이다. 총 108,514 레코드를 사용하고 표본 1만 행으로 대체하지 않는다. 이 합은 고유 업소 108,514개가 아니다. industry-codes-2023.csv 247행과 ulsan-report-template.pptx 양식을 첨부한다. 원본은 바꾸지 않고 새 XLSX/PPTX를 받는다. 실제 파일 도구가 처리한 행수와 남은 범위를 기록한다.

s2 초보자가 따라갈 네 단계
1. 이 자료집의 all-references.txt 한 개를 자료 기반 AI의 소스로 등록한다. ZIP나 HWP를 반드시 직접 읽게 할 필요는 없지만 표·항목이 모호하면 공식 원본 HWP를 확인한다.
2. 아래 요청으로 적용할 자료 뜻·주의사항과 다른 AI에게 줄 실행 프롬프트를 받는다. 답변의 두 부분을 함께 복사한다.
3. 파일 작업 AI에 실제 두 CSV·코드표·PPTX 양식과 복사한 답변을 첨부해 작업시킨다. 자료 기반 AI의 대화/ 파일이 자동으로 넘어가는 것은 아니다.
4. 실제 XLSX/PPTX 다운로드를 받아 편집기로 연다. 도구가 집계 합·조인·출처를 검토하게 하고 제목·표의 수정 가능성과 글자 잘림을 확인한다. 수식·A1 주소·코드 입력·자기평가 표·답 맞추기 활동은 필수 과정이 아니다.

s3 파일 작업 AI가 할 분석
분기별 전체 행·열·식별자 유일성·코드 값·좌표/ 주소 품질 확인 →247 코드표 결합과 명칭 버전 보존 →구군 × 대/ 중분류 집계·비중 →코드로 정한 관심 소분류의 행정동 분포 →식별번호 양쪽 관찰/ 현재만/ 이전만 구분 →속성 차이와 좌표/ 주소 관계 확인 →XLSX 차트·편집 PPT 제작 순서다. 관심 소분류는 예를 들어 카페를 코드표에서 찾아 정의하고 상호 키워드 검색으로 대체하지 않는다. 구군별 합·업종별 합·관심 업종 동별 합·조인 전후 행수와 실제 읽은 전체 범위를 도구가 검산한다. 학생이 수식을 직접 작성하도록 돌려 보내지 않는다.

s4 XLSX와 편집 가능한5장 PPTX
XLSX는 원본 보존 또는 변경 없는 원본 연결, 정리/ 코드조인, 품질, 구군 × 업종, 행정동 × 관심 업종, 두 분기 비교, 차트, 출처를 담는다. 원본 39열을 보존하고 파생 열은 다른 이름으로 붙인다.
PPT1 장: 공식 출처·두 기준일·전체 처리 규모·분석 질문
2장: 구군 업소 수와 업종 구성(수와 비율의 분모 구분)
3 장: 구군 × 중분류 및 관심 업종의 행정동 분포
4장: 두 분기 관찰 여부·속성 차이(개업/ 폐업/ 이전으로 단정하지 않음)
5장: 출처 차이·명칭 버전·좌표 해석·자료 없는 지표 등 한계와 후속 작업
실제 PPTX 양식을 읽고 장별 역할에 맞춰 채운다. 제목·본문·표는 개별 수정 가능하게 하며 이미지 차트/ 지도이면 명시한다. 없는 매출·인구·효과를 채워 넣지 않는다.

s5 자료 기반 AI에 보낼 통합 요청
첨부한 공식 자료와 강사 업무 지시를 구분해, 울산광역시 상가업소 두 분기의 지역·업종 분포 보고를 준비해 줘.

[1. 이번 업무에 사용할 자료 뜻과 주의사항]
공식 OpenAPI 활용 가이드의 전체 추출문, 공식 39개 항목 설명과 실제 CSV 열 대응, 공식 2023 업종 코드표, 두 분기 파일 메타데이터·README를 참고해 식별번호·행정동/ 법정동·업종 분류·좌표의 뜻을 설명해 줘. 문서 이름·버전·관련 위치를 붙여 줘. 공식 원문에 서로 다른 설명이 있으면 원문을 바꾸지 말고 차이를 밝혀 줘. 강사가 정한 보고 구성은 공식 기관 규정이라고 표현하지 마.

[2. 파일 작업 AI에게 그대로 줄 실행 프롬프트]
다른 AI에는 ulsan-202606.csv와 ulsan-202609.csv 전체, industry-codes-2023.csv, ulsan-report-template.pptx 양식을 첨부할 예정이다. 두 CSV는 ulsan-two-quarters.zip으로 함께 전달할 수도 있고, 도구가 ZIP을 풀지 못하면 두 CSV를 직접 첨부한다. 원본 두 파일은 각 54,737행·53,777행,39개 열이며 총 108,514개 원본 레코드다. 이는 서로 다른 108,514개 업소라는 뜻이 아니다. 위에서 확인한 기준과 주의사항도 실행 요청 안에 포함해 줘.
파일 작업 AI가 원본 전체를 읽어 구군 × 업종 구성, 관심 소분류의 행정동 분포, 분기 간 식별번호 관찰 여부와 속성 차이를 계산하고 XLSX와 양식에 맞춘 편집 가능한 5장 PPTX를 새 파일로 만들게 해 줘. 구군별 합계·업종별 합계·관심 업종 동별 합계·조인 전후 행 수를 도구가 검산하게 해 줘. 원본은 보존하고 식별자·지역·업종 코드는 텍스트로 읽게 해 줘. 두 상가 CSV는 UTF-8,2023 코드표는 CP949이므로 각각 실제 한글과 열을 확인하게 해 줘.
2023 코드표 이름으로 2026 CSV 이름을 덮어쓰지 않게 해 줘. 코드는 연결되지만 명칭 버전 차이가 있다는 사실과 공식 설명 충돌을 기록하게 해 줘. 이전·현재 관찰 차이를 신규 개업·폐업이나 좌표 차이를 이전으로 단정하지 않게 해 줘. 매출·수익·유동 인구·인구 분모는 제공되지 않았다.
XLSX에는 원본 또는 변경 없는 원본 연결, 정리·코드조인, 품질, 구군 × 업종, 행정동 × 관심 업종, 두 분기 비교, 차트, 출처를 남기게해 줘. PPT 제목·본문·표는 각각 수정할 수 있게 하고 차트나 지도가 이미지면 그 사실을 표시하게 해 줘. 같은 코드의 분류 이름이 다르면 원문 두 값을 모두 남기게해 줘.
사람이 셀 주소·수식·코드를 직접 입력하는 절차 대신 파일 작업 AI가 처리할 지시로 써 줘. 실제 읽은 파일·전체 범위·사용한 처리 도구·생성한 다운로드를 구분하고 실행하지 못한 것은 미수행으로 표시하게 해 줘. 아직 원본 파일을 받지 않은 이 단계에서 전체 집계를 실행했다거나 완성 XLSX/PPTX를 만들었다고 말하지 마.

최종 답변은 위 두 부분을 모두 복사해 다른 AI로 옮길 수 있게 작성해 줘. 질문에 답을 맞추는 활동이나 자기평가 양식은 만들지 마.
