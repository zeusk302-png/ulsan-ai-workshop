O16 · 차트 단위와 요약 셀 연결

차트

s1 · 수행 조건

프로그램별 참여 막대는 명 단위를 쓰고 0 기준 축으로 표시한다. 원본 1만 행을 그대로 그리지 않고 같은 조건의 집계 표를 사용한다.

s2 · 예외·실패 사례

참여율 %· 만족도 점· 응답자 명을 하나의 수치 축으로 비교하지 않는다. 그림에 숫자가 있다고 요약 셀과 연결됐다는 뜻은 아니다.

s3 · 남길 증거

범주/값/요약셀/회차/단위/축을 기록하고 세 프로그램 합을 참여건수와 대조한다.

s4 · 잘못된 축과 숫자 복사를 분리하는 차트 검사

프로그램 참여 표는 3,815·2,438·1,256명이다. 차트에서 세 막대와 레이블이 같은 숫자를 보여 주는지 확인한다. 축을 최소 3,000부터 시작하면 작은 차이를 과장할 수 있으므로 이 인원 막대 예시는 0 기준 축을 사용한다. 참여율 76.4와 만족도 3.81을 같은 축에 추가하면 단위가 달라 비교의 의미가 흐려진다. 검토자는범주명과요약셀주소를 연결하고 회차 전환 시 차트 원본이 R02 표로 바뀌는지 확인한다. 그림으로 붙여 넣은 차트는 엑셀 표와 자동 연결되지 않을 수 있으므로 새로 만든 그림인지 기록한다. 단위 명· 분모· 회차· 가상 자료 표시는 차트 바깥에만 숨기지 않고 읽을 수 있는 위치에 둔다.
