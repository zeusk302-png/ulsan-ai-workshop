O03 | 결측 ID 처리 사례
강사 제작 가상 교육사업 문서. 실제 울산대학교·기관의 정책, 공문, 성과, 법적 기준이 아닙니다.
분류: 운영·검증 | 버전: 1.0 | 시행일: 2026-11-06 | 상태: current
적용: R01·R02 가상 교육사업 | 상위: B01
요약: 누락

s1 수행 조건
ID 공란 행은 점수가 5이고 참여가 Y여도 제외한다. 행 번호를 ID로 대체하거나 이전행 ID를 아래로 채우지 않는다.

s2 예외·실패 사례
공백만 있는 ID는 앞뒤 공백 제거 후 공란으로 판단한다. 프로그램 값이 있어도 식별자 누락을 해소하지 않는다.

s3 남길 증거
정리 장부에 원문ID·정규화ID·제외사유를 두고 누락 47건 검산을 실제 처리 뒤 대조한다.

s4 식별자가 없는 고득점 응답의 처리
가상 행 31은 ID가 공란이고 참여 Y· 만족도 5다. 담당자는 좋은 응답을 버리는 것이 아깝다며 원본 행 번호 31을 새 ID로 채우려했다. 그러나 운영 기준은 ID 추정을 금하고 있어 이 행은 제외다. 고득점이라는 결과에 맞춰 신청 식별 규칙을 바꾸면 평균과 참여 분모를 임의로 유리하게 만들 수 있다.

복구 기록: 원본 ID 공란을 그대로 두고 정리 ID도 공란으로 표시한다. 최종 판정은 제외, 사유는 ID 누락, 참여· 응답· 점수기여는 0이다. 원본 행 31이라는 추적 값은 식별자 대체가 아니라 원래 위치를 찾는 포인터로만 쓴다. 같은 공란 ID들을 하나의 실제 사람으로 합치는 것도 금한다.

s5 판정표와 인수 조건
ID 공란·Y·5 | 제외· 기여 0
ID 공백만·N· 공란 | 정규화 후 공란· 제외
ID 정상·Y· 공란 | ID 누락 아님· 채택 후 미응답
ID 정상· 대기·5 | ID 누락 아님· 보류
위 표는 해당 문서의 조건을 작은 사례로 검토하는 도구다. 원본 전체의 실제 처리 기록, 사용한 파일· 회차· 도구, 확인하지 못한 사항은 별도의 실행 장부로 남긴다.
