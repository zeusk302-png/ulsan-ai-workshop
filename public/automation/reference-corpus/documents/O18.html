O18 · 이미지 차트의 수정 책임

운영·검증 | v1.0 | 시행 2026-11-06 | 상태 current
범위: R01·R02 가상 교육사업 | 상위: B01

PPT 객체

s1 · 수행 조건

제목· 본문· 표는 편집 가능한 요소로 유지한다. 차트가 이미지라면 이미지임을 밝히고 원본 엑셀과 이미지 생성 근거를 보존한다.

s2 · 예외·실패 사례

이미지 차트를 클릭해서 데이터 셀을 수정할 수 있다고 안내하지 않는다. 통 이미지 슬라이드에 텍스트를 겹친 것만으로 모든 내용의 편집성이 해결되지는 않는다.

s3 · 남길 증거

텍스트 한 글자·표 셀 한 개를 실제 수정하고 차트 선택 객체와 원본 파일을 기록한다.

s4 · 선택 경계가 알려 주는 편집 가능성

PPTX를 열어 슬라이드 전체를 클릭했을 때 선택 경계 한 개만 보이고 텍스트 커서가 들어가지 않으면 통 이미지일 수 있다. 반면 제목만 선택하고 글자를 바꿀 수 있다면 그 제목은 개별 객체다. 표셀을 고칠 수 있는지와 차트 데이터를 고칠 수 있는 지는 다른 검사다. 결과인 수에는 텍스트· 표· 차트별 상태를 따로 적는다. 이미지 차트를 유지하는 경우 원본 엑셀과 다시 그리는 절차를 남기고 편집 가능 차트라고 표현하지 않는다. 통 이미지를 PDF로 내보냈다가 PPTX로 다시 저장해도 개별 원본 객체가 자동 복원됐다고 가정하지 않는다. 실제 수정을 수행한 증거만 완료로 기록한다.

s5 · 판정표와 인수 조건

제목 커서 진입 | 텍스트 수정 가능 표 셀 입력 가능 | 표 수정 가능 차트 그림만 선택 | 데이터 직접 편집 미확인 전체 이미지 하나 | 개별 요소 편집 불가 또는 제한 위 표는 해당 문서의 조건을 작은 사례로 검토하는 도구다. 원본 전체의 실제 처리 기록, 사용한 파일· 회차· 도구, 확인하지 못한 사항은 별도의 실행 장부로 남긴다.
