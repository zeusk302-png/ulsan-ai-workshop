참여자와 응답자 범위의 차이를 보관한다.

s1 · 보관 범위

가상 교육 사업의 기준 일 2026-11-06 검산 스냅샷이다. 과거 보고는 결과 참고이며 현재 계산을 지배하는 규칙 문서가 아니다. 실제 AI 실행· 기관 성과를 증명하지 않는다.

s2 · 확인한 수량·연결

R01 참여 7,509· 유효응답 7,181· 미응답 173· 불량 155. R02 참여 7,677· 유효응답 7,340· 미응답 181· 불량 156. 각 회차 참여 =세 응답 상태 합이다.

s3 · 해석 한계·재확인

미응답· 불량을 평균에서 뺀 것이 참여까지 제거한 것은 아니다. 회차별 유효 응답 비율을 새로 보고 하려면 그 산식과 분모를 별도 적는다.

s4 · 응답 범위 변화와 미응답 해석의 검토

두회차모두 참여자 중 일부는 유효 만족도 응답에 포함되지 않는다. R01 미응답 173· 불량 155, R02 미응답 181· 불량 156이다. 유효 응답 수가 159 늘었다는 관찰과 미응답률이 왜 달라졌다는 원인 설명은 다르다. 원인 자료가 없으므로 접속 오류· 불만· 설문 안내 방식 같은 가정을 확정하지 않는다. 응답 범위 표는 참여자 중 유효 응답/ 미응답/ 불량의 건수와 각 범주의 조건을 제시한다. 비참여자의 점수는 이 분모 구조에 넣지 않는다. 유효 응답 비율을 새로 계산한다면 분모가 참여 건수임을 적고 기존 참여율과 다른 이름을 쓴다. 참여율의 채택 분모 9,824와 응답 비율의 참여 분모를 바꿔 쓰지 않는다.

s5 · 오류 초안과 정정 문장

오류 초안은 “미응답자는 불만족해서 대답하지 않았다”다. 정정은 “미응답 상태의 원인은 제공 자료로 확인하지 못 했다”다. 만족도 평균을 제시할 때 응답 범위와 제외 조건을 함께 설명하는 이유는 평균이 누구를 대표하는지 알리기 위함이다. 전체 주민의 만족이나 모든 참여자의 잠재적 점수를 대표한다고 확대하지 않는다.

s6 · 완료 판정·증빙 검토 이력

검토 기록은 응답 상태 판정 열· 상태별 합· 점수 유효 조건· 원본 표본· 보고 문장을 연결한다. 미응답을 0점으로 채운 이 전 코드를 발견하면 원문 공란을 복원하고 응답· 점수 기여를 다시 만든다. 참여 기여는 그대로 유지되는지 확인하고 요약·PPT의 응답 수와 분모를 재대조한다. 과거 보고의 검산값 수치를 복사하는 대신 실제 처리 근거를 남긴다.
