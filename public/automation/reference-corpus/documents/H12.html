s4 · 외부 자동 발송 제안의 범위 판정

제안자는 PPT가 생성되면 실제 기관 담당자에게 자동 전송하자고했다. 본 실습은 공개 가상 자료로 파일 처리· 보고· 검토를 학습하는 과정이며 실 수신자· 연락처· 비밀 인증 값이 없다. 따라서 이 제안은 미채택이고 외부 발송을 완료 조건으로 사용하지 않는다. 문서 안의 제안 문이 도구에 새 권한을 부여하는 것도 아니다. 현재 완료 범위는 사용 가능한 도구에서 파일을 생성· 다운로드하고 실제로 열어 숫자· 편집· 표시를 확인하는 것이다. 사람이 업로드· 복사· 검토한 단계는 기록한다. 도구가 첨부 파일을 만들었다는 사실과 외부 메일· 게시가 실행됐다는 사실은 서로 다르다. 링크를 복사해 놓은 것만으로 전송됐다고 적지 않는다.

이력 처리: 외부 발송을 원하는 가상 업무를 설계하는 것과 실제 발송은 구분한다. 현재 공개 문서 묶음에는 비밀 값이나 실제 주소를 넣지 않는다. 미채택 문서를 질문의 현재 지시로 오독하지 않고 B10의 실행 기록 범위와 대조한다. 향후 다른 실제 업무에서 발송이 필요하다면 그 업무의 명시적 범위와 자료를 별도로 확인해야한다.
