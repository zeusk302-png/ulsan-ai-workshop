O22 | 작업 시간·수동 단계 기록
강사 제작 가상 교육사업 문서. 실제 울산대학교·기관의 정책, 공문, 성과, 법적 기준이 아닙니다.
분류: 운영·검증 | 버전: 1.0 | 시행일: 2026-11-06 | 상태: current
적용: R01·R02 가상 교육사업 | 상위: B01
요약: 실행 기록

s1 수행 조건
준비· 처리· 사람 검토 시간을 실제 측정한 경우에만 기록한다. 업로드· 복사· 파일 열기· 수정은 수동 단계로 표시한다.

s2 예외·실패 사례
한 번 파일을 만들었다고 완전 자동화나 시간 90% 절감을 주장하지 않는다. 도구 대기 시간과 검토 시간을 빼고 전체 시간을 설명하지 않는다.

s3 남길 증거
시작/종료/활동/수동여부/미측정의 일지를 남긴다. 비교 기준 시간이 없으면 절감률은 미확인이다.

s4 시간 절감률을 말하기 전에 필요한 기록
가상 작업에서 파일 처리 도구의 실행 시간이 2분이었다고 가정해도 전체 업무 시간이 2분이라는 뜻은 아니다. 파일 준비· 첨부· 기준 확인· 다운로드· 사람 검토· 수정을 포함해야한다. 이 문서의 예시 시간은 실측 성과가 아니라 어떤 구간을 기록해야하는지 설명하는 가정이다.

실제 비교를 하려면 동일 업무의 기존 방식과 새 방식에서 포함 범위를 맞추고 각 구간을 측정한다. 기존 방식 시간을 모르면 절감률을 계산하지 않는다. 계정 대기 시간이나 지원 실패를 기록에서 빼고 완전 자동화라고 표현하지 않는다. 사람이 한 복사· 업로드· 검토는 수동 단계로 남긴다.

s5 판정표와 인수 조건
준비 | 시작/ 끝 실측
처리 | 도구실행 실측
검토 | 사람 확인 실 측
대기· 실패 | 별도 포함
비교 기준 없음 | 절감률 미확인
위 표는 해당 문서의 조건을 작은 사례로 검토하는 도구다. 원본 전체의 실제 처리 기록, 사용한 파일· 회차· 도구, 확인하지 못한 사항은 별도의 실행 장부로 남긴다.
