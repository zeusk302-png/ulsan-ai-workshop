B12 | 문서 묶음 업무 요청·자습 경로
강사 제작 가상 교육사업 문서. 실제 울산대학교·기관의 정책, 공문, 성과, 법적 기준이 아닙니다.
분류: 핵심 안내 | 버전: 1.0 | 시행일: 2026-11-06 | 상태: current
적용: R01·R02 가상 교육사업 | 상위: B01
요약: 학습 안내

s1 적용 조건
수업 핵심 경로는 B01~B12 중 질문에 필요한 8~12개 문서다. 먼저 B01·B02로 적용 범위를 정하고 B03~B08로 근거 표와 계산을, B09~B11로 전달과 반복을 확인한다. 72개 전체를 수업 중 읽는 과제가 아니다.

s2 예외·혼동 주의
업무 요청을 선택하고 적용 문서를 검색한다. 프로그램 P 문서, 운영 O 문서, 변경 H 문서, 과거 보고 R 문서는 필요한 경우에만 확장한다. 폐기· 예정 자료를 현재 기준으로 사용하지 않는다. 전체 문서를 다 읽는 대신 실행에 필요한 원문을 확인하고 산출 물 제작으로 이어 간다.

s3 관찰·검증 기록
복사한 업무 요청과 실제 첨부 파일을 사용 가능한 AI 도구에 전달한다. 자료 조회· 전체 파일 처리· 엑셀 재계산·PPT 생성 중 수행한 범위를 구분한다. 결과 파일에서는 숫자· 분모· 회차· 출처· 편집 가능성을 확인한다. 원문을 읽는 단계와 실제 파일을 만드는 단계를 연결해 작업을 이어 간다.

s4 웹 자료만으로 진행하는 질문 중심 자습
첫 단계는 72개 문서를 차례대로 읽는 것이 아니라 지금 만들 산출 물에 맞는 업무 요청을 선택하는 것이다. Q01은 현재 적용 기준 선택, Q04는 두 지표의 분모, Q06은 같은 표시 평균을 가진 새 회차 재실행, Q10은 편집 가능한 PPT와 후속 표기 변경을 다룬다. B01~B12의 핵심 문서 중 필요한 범위를 읽고 관련 프로그램· 운영· 변경 문서로 확장한다. 문서가 많아도 질문에 관계 없는 문장까지 모두 요약해 전달할 필요는 없다.

AI에 전달할 것은 원문 자료, 실제 입력 파일, 원하는 산출 물, 적용할 조건이다. 웹 자료에서 파일을 내려받고 현재 도구에 첨부했는지 확인한다. 로컬 도구에서는 현재 작업 위치와 읽을 경로를 확인한다. 문서 이름을 요청에 적었다는 사실만으로 AI가 내용을 이미 읽었다고 가정하지 않는다. 입력 파일을 읽지 못하면 지원 상태와 남은 작업을 표시하고 예시 검산 파일을 실제 원본처럼 처리하지 않는다.

관련 원문은 계산 조건을 고정하고 산출 물을 검토하는 데 사용한다. 분모가 명확하면 엑셀의 분자· 분모· 기여 열을 확인하고, 편집 요구가 명확하면 PPT의 텍스트· 표· 차트 객체를 확인한다. 원문에 없는 목표· 실제 성과· 원인· 비용을 추가하지 않는다. 인용 링크는 원문 위치로 이동하는 수단이며, 그 문장이 실제 주장과 일치하는지는 파일 제작과 검토 과정에서 확인한다.

이 웹에서 가능한 자료 검색· 원문 확인· 작은 원리 모형 조작과 외부 AI 도구에서 실행하는 전체 1 만 행 처리·XLSX 재계산·PPTX 생성을 구분한다. 도구가 실제 파일을 만든 뒤에는 열어서 숫자· 회차· 분모· 출처· 가상 자료 표시· 잘림을 확인한다. 수동 업로드나 복사· 수정이 있었다면 작업 기록에 남겨 다음 회차에 이어 간다. 실행이 끝나지 않은 단계는 미수행으로 표시한다.
