s3 · 해석 한계·재확인

전체 참여자를 만족도 분모로 바꾸거나 공란을 0점 처리하지 않는다. 본 표는 응답자 평균이며 전체 주민의 만족이 아니다.

s4 · R01 응답 평균의 대상과 계산 재료 검사

요약 B9는 유효 응답 7,181·B10은 점수 합 27,379·B11은 평균 B10/B9다. 별도로 B14 미응답 173·B15 불량 155를 확인한다. 참여 7,509 =유효 응답 7,181 +미응답 173 +불량 155는 만족도 대상인 참여자를 세 응답 상태로 나눈 관계다. 신청 N의 점수가 있어도 이 세 상태의 대상에 자동 포함하지 않는다. 점수 검사에서 숫자 1~5라는 범위뿐 아니라 정수 조건을 확인한다. 2.5를 반올림해 3으로 만들거나 문자 응답을 기분 좋게 해석해 5점으로 바꾸지 않는다. 본 실습 XLSX의 숫자 값 처리와 확장 CSV의 숫자 문자 변환도 구분한다. CSV에서는 해석 가능 문자를 별도 숫자열로 옮긴 뒤 유효 조건을 검사하지만 원문은 보존한다. 이 차이를 모든 문자 점수 허용으로 읽지 않는다.

s5 · 오류 초안과 정정 문장

오류 초안은 “참여자 7,509명의 평균 만족도는 3.81”이다. 계산 평균의 응답자는 7,181이므로 정확한 문장은 “채택 +Y 참여자 중 유효 응답 7,181명의 점수 합 27,379를 나눈 평균 3.81/5점”이다. 참여자 전체가 답한 것처럼 보이게 쓰지 않고 미응답 173· 불량 155를 함께 설명한다. 미응답이 불만 때문이라는 원인 해석은 자료가 없어 미확인이다.

s6 · 완료 판정·증빙 검토 이력

완료 검사는 두 분모의 조건· 점수 합 범위· 응답기여열· 미응답/ 불량 합계· 표시 반올림이다. 계산기 검 산은 27,379/7,181을 사용하고 표시 평균 3.81에 7,181을 곱해 점수 합을 복원하지 않는다. 중간 반올림은 정보를 잃기 때문이다. 프로그램별 평균 요청은 별도 집계가 필요하며 전체 평균을 복사하지 않는다. 실제 수식 파일 미확인 상태는 보고 끝에 남긴다.
