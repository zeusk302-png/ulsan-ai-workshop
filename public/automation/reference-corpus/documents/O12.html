분류

s1 · 수행 조건

디지털기초· 생활문화· 진로탐색의 실제 원 문명과 표준명을 대응한다. 새 별칭을 발견하면 근거 없는 자동 치환 대신 미확인 목록에 둔다.

s2 · 예외·실패 사례

새 별칭 표를 만들더라도 과거 원문을 덮어 쓰지 않는다. 본 실습 제공 검 산 값을 맞추려고 임의로 프로그램을 옮기지 않는다.

s3 · 남길 증거

원문명/표준명/근거/검토자상태를 기록하고 매핑 전후 건수 및 미매핑 건수를 대조한다.

s4 · 미매핑 값을 발견한 분류표의 보완

별도 자습 데이터에"디지털 입문"이라는 새 값이 들어왔다고 가정한다. 담당자는 디지털기초와 비슷하다고 보지만 현재 가상 규칙에는 그 별칭의 대응이 명시되지 않았다. 임의 치환하면 프로그램별 비율과 차트 범주가 바뀔 수 있으므로 미매핑 목록을 만들고 확인 상태를 남긴다. 원문 명· 표준명 후보· 근거 문서· 시행 범위· 검토 상태를 별 도표로 관리한다. 새로운 대응이 확인되면 적용한 복사 본과 출력 파일을 구분하고 매 핑 전후 건수를 대조한다. 현재 본 실습의 세 프로그램 검 산 값을 맞추기 위해 임의 분류하지 않는다. 프로그램 명 처리도 데이터 해석 규칙의 일부이며 디자인의 색상 선택과 다르다.

s5 · 판정표와 인수 조건

디지털기초 | 표준명 확인 생활문화 | 표준명 확인 진로탐색 | 표준명 확인 디지털 입문(추가가정) | 미확인· 임의치 환 금지 위 표는 해당 문서의 조건을 작은 사례로 검토하는 도구다. 원본 전체의 실제 처리 기록, 사용한 파일· 회차· 도구, 확인하지 못한 사항은 별도의 실행 장부로 남긴다.
