s1 적용 조건
1 장은 범위와 가상 자료,2 장은 정리 결과,3 장은 참여율· 프로그램 참여,4장은 만족도와 분모,5장은 확인 사항· 한계· 다음 작업을 담는다. 각 수치를 요약 시트 셀과 연결한다.

s2 예외·혼동 주의
PPTX 확장자만으로 편집 가능하다고 판단하지 않는다. 제목 한 글자와 표의 숫자를 직접 바꿔 본다. 차트가 이미지이면 표시하고 원본 엑셀을 보존한다. 전체 통 이미지는 편집 가능한 표와 다르다.

s3 관찰·검증 기록
가상 자료· 회차· 분모· 단위· 출처를 넣고 실제 화면에서 잘림· 한글· 대비를 확인한다. 이 문서는 가상 보고 구성 기준이며 실제 기관 제출 양식이라는 주장을 금한다.

s4 PPTX 객체를 직접 만져 보는 인수 검사
검토 대상: 같은 모양의 슬라이드 두 개가 있다. 하나는 제목 텍스트· 본문 텍스트· 표· 차트 이미지로 구성되고, 다른 하나는 전체 화면 이미지 한 개다. 두 파일 모두 PPTX로 저장될 수 있으므로 확장자만으로 수정 범위를 알 수 없다. 검토자는 제목 한 글자를 바꾸고 표의 숫자 한 개를 고친 뒤 선택 경계가 무엇을 둘러싸는지 확인한다.
객체별 판정: 텍스트 커서가 들어가면 해당 글은 수정 가능, 표 셀의 값을 바꿀 수 있으면 표는 수정 가능이다. 차트가 그림이라면 원본 데이터를 직접 고칠 수 있는 차트라고 부르지 않는다. 그림 차트의 숫자를 바꿔야할 때는 엑셀 집계 표를 갱신해 그림을 다시 만드는 절차를 기록한다. 통 이미지에는 제목을 덧씌워 수정할 수 있어도 원래 내용이 개별 객체가 된 것은 아니다.
출처 연결: 3장의 참여율 76.4%는 분자 7,509· 분모 9,824와 함께 확인하고 4장의 만족도 3.81은 점수 합 27,379· 응답 7,181을 근거로 둔다. 수치의 크기· 색· 글 꼴을 바꿔도 가상 자료 표시와 분모가 사라지지 않아야한다. 출처를 미세한 글씨로 넣기만하고 실제 발표 환경에서 읽을 수 없다면 근거 전달은 부족하다.
원칙 선택: 참고 자료 하나와 디자인 원칙 두 개를 선택하는 수업 범위를 지킨다. 스킬은 절차와 검토, 라이브러리는 파일 생성 기능, 템플릿은 배치 틀, 아이콘· 글꼴은 시각 재료다. GitHubREADME를 읽은 상태와 필요 도구를 설치· 실행해 PPTX를 생성한 상태를 구분한다. 실제 파일이 없으면 수정안· 코드· 목차를 완성 PPTX라고 부르지 않는다.

s5 디자인 수정에서 숫자의 출처를 유지하는 사례
발표 담당자는 검산한 엑셀과 기존 PPT를 준비한 뒤 디자인 참고 자료 하나를 골랐다. 요청은 새로운 내용을 많이 추가하는 대신 슬라이드의 질문과 근거 위치를 분명하게 하는 방향으로 작성했다. 데이터 근거에는 운영 기준과 검산 XLSX를, 디자인 참고에는 배치와 읽기 쉬움의 방법을 적었다. 디자인 예제의 숫자나 성과 문장이 현재 사업의 사실로 들어오지 않도록 두 입력의 역할을 구분한 것이다.

참여 결과 장에는 참여율과 프로그램별 참여 인원을 배치했다. R01 본 실습의 프로그램 참여 인원은 디지털기초 3,815명, 생활문화 2,438명, 진로탐색 1,256명이며 합계는 참여 7,509명과 연결된다. 이 값은 참고 디자인의 임의 막대 높이로 바꾸지 않는다. 막대에는 범주명과 명 단위, 직접 숫자를 표시하고 같은 축에서 비교한다. 참여율과 만족도는 단위가 다르므로 한 축에 올려 크기를 비교하는 장식을 피한다.

초안이 완성되면 제목 한 글자와 표의 숫자 한 칸을 실제로 선택해 수정해 본다. 한 장 전체가 이미지라면 확장자가 PPTX여도 그 안의 제목을 텍스트처럼 고칠 수 없다. 차트가 이미지인 경우에는 이미지라는 사실과 원본 집계표의 위치를 남긴다. 글자가 수정되는 것과 숫자가 맞는 것도 별도다. 숫자를 손으로 바꾸면 편집에는 성공했더라도 검산 셀과 연결이 끊길 수 있으므로 수정 뒤 원본 셀을 다시 대조한다.

디자인 전후를 비교할 때에는 설명하려는 조건만 바꾼다. 글자 크기의 효과를 보여주려면 내용과 서체, 굵기와 색을 유지하고 크기만 다르게 놓는다. 정렬을 설명할 때에는 같은 항목의 시작선을 맞춘다. 색에 의존하지 않는 차트를 만들 때에는 같은 값과 축을 유지하고 범주명과 직접 숫자를 더한다. 제목·출처·색·값을 동시에 바꾸면 무엇 때문에 읽기 쉬워졌는지 판단하기 어렵다. 발표자의 취향에 맞는 장식과 자료를 정확히 읽게 하는 조건을 구별한다.

검토 중 PPT의 참여율만 집계표와 다르면 먼저 어느 단계에서 다른 값이 들어갔는지 확인한다. 엑셀 집계가 맞고 PPT 표시만 다르다면 원본행을 바꾸지 않고 해당 슬라이드 요소를 집계 셀에서 다시 만든다. 수정 전 파일은 보존하고 새 이름으로 저장해 비교 가능하게 둔다. 마지막에는 수치·분모·단위·회차·출처·교육용 가상자료 표시를 확인하고 실제 발표 화면에서 글자 잘림과 대비를 살핀다. 자동 접근성 검사 결과가 있더라도 수치의 의미와 실제 읽힘을 모두 대신하지는 않는다.

다른 PC로 전달할 때에는 파일이 열리는지만 보지 않고 한글 줄바꿈과 출처 위치도 살핀다. 제작 환경의 글꼴이 없으면 대체 글꼴 때문에 같은 문장이 다른 줄 수를 차지할 수 있다. 수치를 줄이거나 분모를 삭제해서 억지로 맞추지 않고 텍스트 상자와 여백을 조정한다. 제작 중 보았던 화면과 최종 전달 파일의 화면을 구분해 기록해야 수정되지 않은 옛 파일을 다시 보내는 일을 피할 수 있다.
