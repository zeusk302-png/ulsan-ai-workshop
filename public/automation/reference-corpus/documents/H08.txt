H08 | 후속 색상·레이블 예고

s1 문서의 결정 내용
후속 자습 차트는 세 프로그램 이름· 명 단위· 숫자를 막대 옆에 직접 표시하고 흑백에서도 구분하는 비교를 만든다. 색상만으로 범주를 구분하지 않는다.

s2 적용 범위·예외
참여 숫자나 프로그램 분류는 바꾸지 않는다. 색· 레이블 개선의 전후 두 파일을 남기며 실제 대비 검사 미실행은 미확인이다.

s3 변경 이력
2026-12-01: 후속 색상·레이블 예고를 가상 문서 대장에 기록했다. 상태는 scheduled다. B02의 시점·상태·범위 판정 후 사용한다. 본 문서는 기존 운영 기준 v2.0 원문을 개정하지 않는다.

s4 색상·직접 레이블 활동의 자료 유지 명세
후속 활동은 한 개의 참여율 숫자를 예쁘게 만드는 것이 아니라 프로그램 세 범주를 색 없이도 구분하는 문제를 다룬다. 같은 프로그램 참여 표를 사용해 색만 있는 차트와 이름· 명· 값을 직접 표시한 차트를 비교한다. 전체 검산 값은 그대로 여야하고 디자인 예제의 임의 숫자를 가져오지 않는다.

적용 예는 R01 디지털기초 3,815명· 생활문화 2,438명· 진로탐색 1,256명이다. 흑백에서도 각 막대의 범주와 숫자를 읽을 수 있는지 검사한다. 차트 이미지를 다시 만들었으면 요약 셀과 일치하는지 확인한다. 색 대비 확인 도구를 사용하지 않았다면 자동 대비 검증 완료라고 쓰지 않고 사람이 확인한 표시 범위만 적는다.

s5 보관·시행 이력과 재검토 조건
효력 경계: 현재 상태는 예정이며 본 실습의 채택· 참여 조건에 예외를 만들지 않는다. 레이블 추가로 슬라이드가 복잡해지면 글자를 무조건 작게 줄이기보다 공간과 메시지 수를 조정한다. 적용한 디자인 원칙· 유지한 숫자· 실제 검토 환경· 미확인을 수정 기록에 남긴다. 통 이미지 PPT를 편집 가능 결과라고 새롭게 부르는 근거도 아니다.

s6 색·레이블 예고의 변경대상과 비대상
대상 | 변경할 수 있는 것 | 바꾸면 안 되는 것 | 관찰 방법
막대 색 | 구분· 대비 개선 | 수치· 분모 | 같은 데이터 비교
범주 이름 | 직접 레이블 위치 | 프로그램 명 임의 변경 | 색 없는 상태
숫자 레이블 | 명 단위와 함께 | 다른 회차값 섞기 | 집계 셀 대조
차트 이미지 | 새로 렌더 | 원본 엑셀 삭제 | 생성 근거 기록
출처 | 읽히는 위치 | 가상· 회차표시 삭제 | 실제 화면 확인

해석 사례: 세 프로그램 이름을 표시하지 않은 차트에서 색만 진하게 만들면 본문과 배경의 대비는 좋아져 도색 의존성은 남을 수 있다. 반대로 이름이 있어도 너무 작거나 잘리면 정보가 전달되지 않는다. 같은 차트의 상태를 바꿔 관찰하고 적용 원칙 두 개를 기록한다. 이 예고는 모든 기기· 모든 사용자 환경에서 접근성이 완벽하다는 보증을 하지 않는다.
