요약: 작품 사진 공개 범위

s1 프로그램 적용
작품 사진이 있다고 참여· 만족도 응답을 추정하지 않는다. 본 실습에는 실 인물· 실 작품 사진이 없고 공개용 가상 자료만 사용한다.

s2 예외·적용 한계
사진 사용 동의나 실제 저작권 상태는 이 가상 문서가 보증하지 않는다. 별도 자료를 가져오는 자습은 이용 조건을 확인해야한다.

s3 프로그램 보고 기록
사용한 이미지 출처·가상 여부·추가 확인 조건을 남긴다.

s4 작품 이미지의 존재와 참여 사실의 경계
생활문화 보고에 작품 사진을 넣고 싶은 상황을 가정한다. 사진이 많아 보인다는 이유로 참여 인원이나 만족도를 추정할 수 없다. 한 사람이 여러 작품을 만들거나 같은 작품을 여러 각도에서 촬영했을 수 있다. 현재 가상 데이터에는 실제 작품 사진과 사진 속 사람의 식별 정보가 없으며, 이 문서의 이미지 사용 예시는 실제 촬영· 동의를 입증하지 않는다.

인수 절차는 자료의 출처· 권리· 실제 여부 확인 →슬라이드에서의 역할 결정 →사실 주장과 분리 →표시 검토다. 이미지는 전달을 돕는 시각 재료이고 통계의 계산 근거가 아니다. 프로그램 이름과 회차가 맞아도 사진 사용 동의 여부는 별도 사실이다. 외부 이미지의 이용 조건을 확인하지 않았다면 확인 완료라고 표시하지 않는다. 이 가상 편람이 제3자 자료의 이용을 허가해 주지 않는다.

s5 부서 검토 회신과 후속 업무
보고 문장 예: “아래 이미지는 설명용이며 참여 수 집계의 근거가 아니다.” 실제 자료가 없는 경우 생성 이미지나 아이콘을 사용할 수 있는지는 선택한 도구· 자산의 조건을 따로 확인한다. 도식이 실제 작품처럼 보이면 설명용 표시를 눈에 띄게한다. 수치 출처는 요약 XLSX로 유지하고 이미지가 숫자· 분모· 가상 자료 표시를 가리지 않는지 실제 화면에서 검토한다.
