숫자 표시

s1 · 수행 조건

계산 중간값을 반올림하지 않는다. 참여율은 표시만 소수 1자리%, 만족도는 소수 2자리/5점이다.

s2 · 예외·실패 사례

표시 평균 3.81을 다시 프로그램 평균의 원 자료로 사용하지 않는다. 원점수 합과 응답 수로 전체 평균을 구해야한다.

s3 · 남길 증거

원 값/ 표시 형식/ 표시 값을 세 열로 남긴다. 회차 비교에서는 R01/R02가 같은 표시 평균을 가질 수 있음을 확인한다.

s4 · 같은 표시에 가려진 차이를 남기는 표

R01원 평균 3.812700181… 과 R02원 평균 3.809400545…는 서로 다르다. 둘을 소수 둘째 자리로 표시하면 3.81이다. 따라서 표시 값 한 개가 같다는 이유로 재실행에 실패했다고 결론 내리면 안 된다. 반대로 표시가 다른 숫자로 바뀌었다는 사실만으로 올바른 입력과 수식을 썼다고 확신할 수도 없다. 기록은 분자· 분모· 원 값· 표시 형식· 표시 값을 연결한다. 참여율은 비율 원 값에 100을 곱한 백분율 표시와 원래 비율을 혼동하지 않는다. 예를 들어 비율 0.7643526은 76.43526%이며 표시 76.4%다. 76.4를 다시 백분율 서식에 넣어 7,640%가 되는 오류를 피하려면 셀의 실제 값을 확인한다.
