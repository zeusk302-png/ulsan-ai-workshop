O10 · 분모 0인 별도 소집단 연습

운영·검증 | v1.0 | 시행 2026-11-06 | 상태 current
범위: R01·R02 가상 교육사업 | 상위: B01

0분모

s1 · 수행 조건

추가 자습 소집단에서 채택자가 0이면 참여율은 미확인이다. 참여자가 있어도 유효 응답이 0이면 만족도는 미확인이다.

s2 · 예외·실패 사례

이 소집단 사례는 R01/R02 전체 지표가 0 분모라는 뜻이 아니다. 두 분모의 0 여부를 독립적으로 검사한다.

s3 · 남길 증거

분모 0 검사 결과와 미확인 이유를 남긴다. 오류를 숨기기 위해 0% 또는 0점으로 바꾸지 않는다.

s4 · 참여율0과 만족도미확인의 차이

별도 복사 본의 가상 소집단 A는 채택 3명 모두 N이다. 참여율은0/3=0%로 계산 가능하지만 만족도는 유효 응답 0이므로 미확인이다. 소집단 B는 채택 2명 모두 Y이나 점수가 공란·6이다. 참여율은2/2=100%이고 만족도는 역시 미확인이다. 소집단 C는 채택 자체가 0이므로 두 지표 모두 분모를 검사해야한다. 미확인을 0점으로 바꾸면 응답이 없는 집단을 낮은 만족도로 오해할 수 있다. 보고 문장에는 미확인 사유를 기재하고 계산 가능한 지표만 제시한다. 이 세 소집단은 조건 학습용이며 실제 R01/R02 전체 분모가 0이라는 뜻이 아니다. 원본 1만행을 이 사례 숫자로 변경하지 않는다.

s5 · 판정표와 인수 조건

A: 채택 3·Y0· 응답 0 | 참여 0%· 만족 미확인 B: 채택 2·Y2· 응답 0 | 참여 100%· 만족 미확인 C: 채택 0·Y0· 응답 0 | 두지표 미확인 위 표는 해당 문서의 조건을 작은 사례로 검토하는 도구다. 원본 전체의 실제 처리 기록, 사용한 파일· 회차· 도구, 확인하지 못한 사항은 별도의 실행 장부로 남긴다.
