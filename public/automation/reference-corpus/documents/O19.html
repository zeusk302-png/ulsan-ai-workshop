글꼴

s1 · 수행 조건

제목· 본문· 숫자를 실제 발표 환경에서 확인한다. 선택한 글 꼴 링크를 주었다고 생성 환경에 설치되거나 PPT에 내장됐다고 말하지 않는다.

s2 · 예외·실패 사례

웹 폰트 적용은 PowerPoint 글 꼴 상태와 별개다. 다른 PC에서 대체되면 줄 바꿈· 잘림을 다시 확인한다.

s3 · 남길 증거

선택글꼴/실제표시/대체글꼴/다른환경검토/미확인을 기록한다. 가상자료 숫자는 디자인 수정 중 유지한다.

s4 · 다른 PC에서 글자가 잘린 경우

생성 환경에서 읽히던 한 글이 발표 PC에서 대체 글 꼴로 표시되어 줄 수가 늘었다. 슬라이드 아래 분모와 출처가 잘렸지만 큰 참여율 숫자만 남아 겉보기에는 정상처럼 보인다. 글 꼴 선택 링크와 실제 설치· 내장 상태는 다르므로 파일을 다른 환경에서 열어 검토한다. 수정은 제목· 본문· 근거 텍스트의 공간과 대체 글 꼴을 확인하는 방향이다. 글씨를 무조건 작게 줄여 필수 근거가 읽히지 않게하지 않는다. 검토하지 못한 발표 환경은 미확인으로 남기며 실행 환경· 사용 글 꼴· 대체 여부를 기록한다. 본 묶음의 웹 폰트나 HTML 표시 성공이 PPT 표시 성공을 보증하지 않는다.

s5 · 판정표와 인수 조건

한글 정상· 숫자 정상 | 해당 환경 표시 통과 대체 글 꼴· 줄 넘침 | 배치재검토 출처잘림 | 완료 보류 다른 PC 미검토 | 미확인 표시 위 표는 해당 문서의 조건을 작은 사례로 검토하는 도구다. 원본 전체의 실제 처리 기록, 사용한 파일· 회차· 도구, 확인하지 못한 사항은 별도의 실행 장부로 남긴다.
