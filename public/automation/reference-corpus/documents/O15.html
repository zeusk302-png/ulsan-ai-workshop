O15 · 재계산·저장 표시 값 검사

운영·검증 | v1.0 | 시행 2026-11-06 | 상태 current
범위: R01·R02 가상 교육사업 | 상위: B01

엑셀 재계산

s1 · 수행 조건

XLSX 수식 입력 줄과 표시 값을 함께 검사한다. 수식이 있어도 생성 환경이나 읽는 프로그램이 계산하지 않으면 표시 값이 비거나 오래된 값일 수 있다.

s2 · 예외·실패 사례

AI가 수식 코드를 작성한 것과 실제 재계산· 저장은 다르다. 재계산 가능한 프로그램으로 열어 저장하고 수행하지 못하면 미수행으로 남긴다.

s3 · 남길 증거

수식/ 재계산 프로그램/ 실행 여부/ 저장후표시/ 독립 검산 값을 기록한다. 표시만 맞고 수식이 빠진 파일도 완료로 보지 않는다.

s4 · 수식 파일을 읽는 프로그램이 계산하지 않는 경우

생성된 XLSX를 열었더니 요약 B8에 수식은 있지만 표시가 비어 있다. AI의 작업 로그에는 수식을 저장했다고만 적혀 있다. 이런 상황에서 검산값 숫자를 말로 답하는 것과 파일의 계산 상태를 확인하는 것은 다르다. 수식 문자열· 저장표시값· 재계산 엔진 실행 여부를 각각 기록해야한다. 가능한 경로는 재계산 가능한 프로그램으로 복사 본을 열고 계산· 저장을 수행한 뒤 다시 읽는 것이다. 계산 엔진을 사용하지 못하면 사용 가능 환경의 한계와 남은 검증을 남긴다. 실제로 열지 않은 프로그램에서 검증했다고 말하지 않는다. 표시 값이 맞더라도 수식이 상수로 바뀌었다면 다음 회차 재현 조건이 깨졌을 수 있으므로 입력 줄을 확인한다.

s5 · 판정표와 인수 조건

수식 있음· 표시 없음 | 계산 완료 미확인 수식 없음· 검산값 상수 | 재현 식 보완 수식 있음· 재계산· 독립 검산 일치 | 계산검토통과 화면미열기 | 표시검증미수행 위 표는 해당 문서의 조건을 작은 사례로 검토하는 도구다. 원본 전체의 실제 처리 기록, 사용한 파일· 회차· 도구, 확인하지 못한 사항은 별도의 실행 장부로 남긴다.
