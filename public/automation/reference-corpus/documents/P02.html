기기 대여 장부 경계

s1 · 프로그램 적용

기기 대여 횟수와 프로그램 참여 인원은 다른 단위다. 한 사람이 기기를 두 번 빌려도 참여 건수는 회차 +ID 최초 후보 기준으로 계산한다.

s2 · 예외·적용 한계

가상 대여 장부는 본 실습 입력에 포함되지 않는다. 대여 실적을 요청 받으면 자료 없음으로 답하며 참여 건수에서 추정하지 않는다.

s3 · 프로그램 보고 기록

참여 집계 출처와 대여자료 미제공 상태를 분리한다.

s4 · 대여 횟수에서 사람 수를 추정하지 않는 검토

가상의 대여 장부에 태블릿 대여 12건이 있고 프로그램 참여 표에는 10명이 있다고 가정한다. 같은 사람이 오전과 오후 두 번 기기를 빌렸을 수도 있고 비참여자의 대여가 포함됐을 수도 있다. 두 장부의 단위와 키를 확인하지 않고 12건을 참여 12명으로 바꾸는 것은 허용되지 않는다. 현재 본 실습에는 대여 장부가 없으므로 실제 대여 실적을 산출할 수 없다. 인수 절차는 자료 존재 확인 →장부 단위 확인 →연결 키와 대상 회차 확인 →신청 통계와 별도 집계다. 나중에 대여 자료가 제공되는 별도 프로젝트라면 대여 건수· 대여자 고유 인원· 프로그램 참여 건수를 각각 정의해야한다. 이 세 값을 하나의 “이용자”로 묶으면 중복과 범위가 보이지 않는다. 회차 +ID라는 현재 신청 키가 모든 장부의 올바른 키라는 가정도 하지 않는다.

s5 · 부서 검토 회신과 후속 업무

예상 질문 “R01 디지털기초 참여 3,815명에게 기기를 모두 대여했나”의 검산값은 미확인이다. 참여 3,815는 신청 기록의 채택 +Y 집계이고 대여 여부 열이 없다. 계산 가능한 참여 숫자는 제시하되 없는 대여 사실은 추가하지 않는다. 검토 표에는 요청한 값, 필요한 자료, 현재 존재 여부, 가능한 분석, 미확인 상태를 남겨 담당자가 다음에 무엇을 받아야하는지 알 수 있게한다.
