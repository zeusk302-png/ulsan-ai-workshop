B11 | R01/R02 재실행·동일 평균 함정
강사 제작 가상 교육사업 문서. 실제 울산대학교·기관의 정책, 공문, 성과, 법적 기준이 아닙니다.
분류: 핵심 안내 | 버전: 1.0 | 시행일: 2026-11-06 | 상태: current
적용: R01·R02 가상 교육사업 | 상위: B01
요약: 재실행

s1 적용 조건
R02는 새 입력으로 전체 정리 →집계 →차트 →PPT를 실행한다. R01 숫자를 복사하지 않는다. 지침· 계산 기준·5 장 구조는 유지하고 입력 회차와 출력 이름은 바꾼다.

s2 예외·혼동 주의
R01과 R02 만족도 표시는 모두 3.81이다. R01 점수 합/ 응답 수는 27,379/7,181이고 R02는 27,961/7,340이다. 반올림 전 평균은 다르므로 표시 평균 하나로 갱신 실패를 판정하지 않는다.

s3 관찰·검증 기록
입력 회차· 전체 행· 판정 합계· 분자· 분모· 차트 원본·PPT 출처를 함께 비교한다. 기준이 바뀐 별도 후속 활동은 근거 표부터 다시 검토하되 본 실습 v2.0 검산 값을 소급 변경하지 않는다.

s4 새 회차의 의존성 점검과 같은 표시값
변경 대상: R01 파일 대신 R02 파일을 읽는 것은 파일 명 교체만이 아니다. 원본 읽기 →정규화· 중복 판정 →행기여 →요약 →차트 →PPT의 종속 결과를 새 입력으로 생성해야한다. 기준 문서가 같으면 정의 표를 유지할 수 있지만 어떤 기준을 사용했는지는 다시 표시한다. 기준이 잘못 적용됐음을 발견하면 근거 표와 영향 받은 하위 산출물을 함께 검토한다.
전후확인표:
원본행 R01 10,000 / R02 10,000
채택 R01 9,824 / R02 9,824
참여 R01 7,509 / R02 7,677
유효응답 R01 7,181 / R02 7,340
점수합 R01 27,379 / R02 27,961
표시만족도 R01 3.81 / R02 3.81
판정 이유: 같은 원본 행수· 채택수· 표시 평균은 재사용의 증거도 실패의 증거도 아니다. 실제 입력 회차· 원본 파일 식별· 판정 장부· 분자· 분모· 반올림 전 평균으로 확인해야한다. 숫자 한 개가 변했다고 전 단계가 올바르게 갱신된 것도 아니다. 제목은 R02 인 데 분모나 차트 출처가 R01인 혼합 파일을 찾는 검토가 필요하다.
변경 범위의 예외: 12월 근거띠· 색상 표기는 산술 변경이 아니다. 이런 후속 활동은 새로운 정리 기준을 발명하지 않고 확인한 수치를 유지한 채 표현을 바꾼다. 기존 회차 결과는 보존하고 refined 파일과 수정 내역 표를 남긴다. 새 기준을 적용했다고 표현하려면 무엇이 바뀌고 무엇이 그대로인지 조항 단위로 설명해야한다.

s5 표시 평균이 같아도 서로 다른 실행을 식별하는 사례
반복 보고 담당자는 R01 결과 파일을 복사하고 제목의 회차만 R02로 바꾼 초안을 받았다. 만족도 표시가 두 회차 모두 3.81이라 초안이 맞아 보였지만, 이 값 하나로 재실행 여부를 알 수는 없다. 반올림한 평균이 같은 것은 원자료와 점수합, 응답 수가 같다는 뜻이 아니다. 새 회차를 처리했다는 근거는 새 입력을 읽고 정리·집계한 연결에서 찾아야 한다.

R01은 점수합 27,379와 유효 응답 7,181을 사용하고 R02는 점수합 27,961과 유효 응답 7,340을 사용한다. 두 비율의 표시가 같더라도 분자와 분모는 다르다. 참여 건수도 R01 7,509명과 R02 7,677명으로 구별된다. 반복 실행 기록은 소수 둘째 자리 평균만 옮기지 않고 입력 회차, 전체 행 수, 채택·제외·보류, 참여와 응답, 점수합을 함께 남긴다. 기존 본 실습 숫자를 보고 문구에 맞추어 임의로 조정하지 않는다.

작업 요청은 고정 조건과 변경 조건을 나누어 적는다. 운영 기준 v2.0과 원본 보존, 판정 순서, 보고 구조는 유지한다. 새 회차의 원본 파일과 출력 파일명, 제목과 날짜는 변경 대상이다. 요청을 받은 AI는 먼저 읽을 입력과 적용 기준을 확인하고 새 원본 전체에서 정규화와 중복 판정을 다시 수행한다. 이전 회차의 채택행을 단순 복사하거나, 같은 ID라는 이유로 서로 다른 회차의 신청을 제거하지 않는다.

새 집계 파일이 생성되면 요약 시트의 숫자뿐 아니라 차트 원본과 PPT 출처도 새 회차를 가리키는지 확인한다. 슬라이드 제목은 R02인데 각주에 R01 요약 시트가 남아 있다면 전달 결과가 혼재한 상태다. 차트의 모양이 비슷하더라도 실제 참조 범위가 새 집계 셀인지 살핀다. 수치가 한 곳에서만 다르면 어느 연결부터 갱신되지 않았는지 확인하고, 해당 단계 이후 산출물을 다시 만든다.

기준 자체가 바뀌는 후속 작업은 데이터만 바꾸는 반복과 구별한다. 기준 변경이 확정되었다면 원문과 근거표의 변경점을 먼저 확인하고 어떤 포함 조건과 산식에 영향을 주는지 정리한다. 이때 기준 문서를 고정한다고 표시하면서 동시에 기준 변경을 적용하는 모순을 남기지 않는다. 다만 현재 본 실습의 검산을 설명하는 문서에서 후속 제안이나 표기안을 이유로 v2.0 계산값을 바꾸지는 않는다.

최종 기록은 반복 실행을 실제로 수행한 범위를 나타낸다. 새 회차 파일을 읽지 못해 템플릿의 제목만 바꾼 경우에는 보고 형식 수정까지만 수행했다고 적는다. 전 행 처리와 집계가 끝났지만 PPT 파일을 열어 보지 못했다면 파일 생성과 화면 검토의 상태를 구분한다. 이 기록을 다음 담당자에게 넘기면 완료한 작업을 다시 추측할 필요 없이 미확인 단계부터 이어갈 수 있다. 반복 가능성은 같은 말을 다시 요청할 수 있다는 뜻이 아니라, 같은 기준으로 새 입력에서 검토 가능한 결과를 다시 얻을 수 있다는 뜻이다.
