RAG·엑셀·PPT 실습 시작

운영 기준을 찾아 엑셀로 계산하고 보고 PPT를 만듭니다. 기준과 데이터는 모두 강사 제작 가상 자료이며, 완성 예시는 외부 AI 실행 결과가 아닙니다.

압축을 풀어 이 페이지를 열었다면 아래 파일이 함께 있어야 합니다. 웹에서 보고 있다면 전체 ZIP을 내려받아 압축을 풀어 시작하세요. 자료 기반 AI 도구와 파일 생성 AI 도구는 직접 열어 사용합니다. 파일 생성·다운로드 가능 여부는 자신의 계정에서 확인하세요.

실습 규모와 순서

준비48행 → 본 실습10,000행 → 선택 확장100,000행 순서입니다. 본 실습의 원본 A2:F10001, 정리 A2:M10001을 전체 검산합니다. 프로그램마다 참여율과 점수 분포가 다르며 누락·중복·보류·문자·0·6·소수·미응답을 구분합니다. 정리는 회차+정규화ID 키로 한 번씩 처리하고 매행 누적 COUNTIF를 반복하지 않습니다.

0. 폴더와 준비 파일

sources는 기준, data는 원본, templates는 PPT 양식, work는 근거표, output은 내 결과, checks는 검산 자료입니다.

  • 운영 기준 TXT / 읽기용 HTML / PDF
  • 1회차 원본 XLSX / 2회차 원본 XLSX
  • 5장 PPT 양식
  • AGENTS.md / CLAUDE.md / 업무 절차
  • 48행 준비연습 / 48행 완성 엑셀 / 48행 완성 PPT
  • 100,000행 CSV 별도 다운로드 (UTF-8 BOM, ZIP에 미포함)

1. RAG로 계산 기준 찾기 · 약 15분

  1. 자료 기반 질문 도구에 운영 기준 TXT 또는 PDF를 새 소스로 등록합니다.
  2. 아래 요청을 입력합니다. 출처 표시를 열어 조항과 원문을 대조합니다.
  3. 확인한 표를 work/evidence.txt에 저장합니다. 이후 파일 생성 도구로 옮길 때 기준 원문과 근거표도 함께 전달합니다.
첨부한 operating-rules 자료만 근거로 다음 질문에 답해줘. 아직 계산하거나 PPT를 만들지 마.
1) 참여율의 분자·분모는 무엇인가?
2) 참가자ID 누락·중복·참여여부 오류·만족도 미응답/불량은 각각 어떻게 처리하는가?
질문 / 기준 / 문서·조항 / 원문 문장 / 확인 상태 표를 만들어줘. 자료에 없는 조건은 미확인으로 남겨줘. 인용이 실제로 그 기준을 지지하는지 확인할 위치도 적어줘.

2. 엑셀 정리·계산·차트 · 약 65분

실제 XLSX를 생성·다운로드할 수 있는 AI 도구에 원본 XLSX, 운영기준, 근거표를 첨부합니다. AGENTS.md가 자동 적용되지 않으면 내용도 직접 전달하세요.

sources/operating-rules.txt와 work/evidence.txt의 확인된 기준을 적용해 data/round-01.xlsx의 원본 시트를 읽고 분석해줘. 실제 파일 생성 기능이 있는 도구에서는 편집 가능한 output/round-01-summary.xlsx로 저장해줘.
원본은 10,000행이다. 덮어쓰지 말고 원본/정리/요약/근거 네 시트를 만들어줘. 원본행 번호·행순서를 유지하고 ID누락·동일회차 후속중복은 제외, Y/N외 참여값은 보류하되 원본값과 사유를 보존해줘. 회차+정규화ID를 키로 한 Python·Power Query 등 선형 전처리로 정리 판정을 만들고 매행 누적 COUNTIF는 쓰지 마. 정리 A-H는 정규화값·판정·사유, I-L은 유효신청·참여수·유효응답·점수합 수식, M은 만족도 처리 상태로 구성해줘. 요약은 SUM/COUNTIF/SUMIF 등 수식으로 참여율·만족도 및 분자·분모를 계산해줘. 프로그램별 참여자 수 차트 하나를 만들어줘. 미응답·불량 점수는 0점으로 바꾸지 마. 근거 조항과 전처리 방법을 보존해줘.
최종 저장 전에 10,000=채택+제외+보류와 전체 10,000행의 판정·수식 결과를 검산해줘. 첫·중간·마지막 행도 열어보고 확인하지 못한 사항을 알려줘. 수식만 텍스트로 설명하고 파일을 만든 것처럼 말하지 마.

다운로드한 파일을 열어 원본/정리/요약/근거 시트, 실제 수식, 참여율 분모와 만족도 분모를 확인합니다. 숫자가 비거나 갱신되지 않으면 자동 계산을 켜고 지금 계산을 실행합니다. 원본은 바꾸지 않습니다.

3. 편집 가능한 보고 PPT · 약 30분

검토한 엑셀 결과, 운영기준, PPT 양식을 첨부합니다. 텍스트 상자를 눌러 글자가 수정되는지 확인하세요.

output/round-01-summary.xlsx와 sources/operating-rules.txt, templates/report-template.pptx를 사용해 교육용 가상 프로그램 운영결과 보고 PPT를 5장으로 작성해줘. 실제 파일 생성 기능이 있는 도구에서는 output/round-01-report.pptx로 저장해줘.
1 보고 범위(10,000행/회차/교육용 가상 자료), 2 데이터 정리(원본/채택/제외/보류), 3 참여율(분자·분모와 프로그램별 참여자 차트), 4 만족도(점수합/유효응답 수/평균), 5 확인할 사항과 다음 작업으로 구성해줘.
숫자는 엑셀 요약만 사용하고 표·텍스트는 편집 가능하게 만들어줘. 차트도 가능하면 편집 가능한 차트로 만들고 불가능한 경우 알려줘. 참여율·만족도 분모와 출처를 표기하고 미확인 원인을 단정하지 마. 생성 후 엑셀 숫자와 슬라이드 숫자를 대조해줘. 이미지 한 장으로 된 PPT는 완료로 처리하지 마.

4. 다음 회차로 재실행 · 약 10분

같은 운영 기준과 작업 순서를 유지하며 입력만 data/round-02.xlsx, 회차만 R02로 바꿔 output/round-02-summary.xlsx와 output/round-02-report.pptx를 생성해줘. R01 수치를 남기거나 두 회차를 합산하지 마.
정리 판정부터 다시 실행하고 I-L 수식·요약·차트를 재계산해줘. 원본 10,000행 전체 보존, 제외/보류 사유, 참여율 분모·분자, 만족도 점수합·분모, 프로그램별 참여 차트, PPT의 회차·숫자·출처를 검토해줘. 이전 회차와 다른 값과 바뀌지 않아야 할 기준을 work/rerun-log.txt에 기록해줘. 실제로 수행하지 못한 작업은 미수행으로 남겨줘.

회차·분모·차트·PPT 숫자가 모두 바뀌었는지 확인합니다. 파일 간 전달은 사람이 합니다. 예약·무인 실행을 구현한 것으로 기록하지 않습니다.

파일 생성이 안 될 때

엑셀 원본을 직접 열고 AI가 제안한 수식을 적용하거나, 완성 엑셀 예시의 정리·요약 수식을 읽고 바꿔봅니다. PPT는 완성 PPT 예시를 열어 숫자·문구를 직접 수정합니다. 계정에서 하지 못한 생성은 미수행으로 기록합니다.

선택 확장 · 100,000행 CSV

Excel의 데이터→텍스트/CSV에서 파일을 열고 UTF-8·쉼표 구분을 확인합니다. 데이터 변환에서 회차·ID를 텍스트로 두고 만족도 원문을 보존한 뒤 별도 숫자값으로 변환합니다. 빈값은 미응답, 숫자 1~5 정수만 유효합니다. 먼저 R01 10,000행만 골라 본 실습과 같은 결과인지 확인한 뒤 R01~R10을 각각 집계합니다. 중복키는 회차+정규화ID이며 같은 ID라도 회차가 다르면 별도 신청입니다. 전체 CSV를 채팅 본문에 붙이지 말고 파일 처리로 실행하세요.

완료 기준

  • 근거표에 기준 조항과 직접 확인한 원문이 있습니다.
  • 엑셀에 수식·분모·제외/보류 사유·프로그램별 참여 차트가 있습니다.
  • PPT가 편집 가능하고 핵심 숫자가 엑셀과 같습니다.
  • 2회차에 같은 기준을 적용하고 이전 수치가 남지 않았는지 확인했습니다.
